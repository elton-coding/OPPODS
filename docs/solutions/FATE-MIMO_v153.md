# FATE-MIMO V153：超高中间 SNR 扩展子区间专家

版本：V153，2026-08-25

V153 在 V152 的高中间 SNR 扩展门控之上增加 0.25 dB 精细专家：仅在 `[-2.75,-2.5) dB` 把截断平均绝对 LLR 门槛从 V152 的 `0.296287667` 提高到 `0.45`。低一致性扩展不再提前返回 1056 bit，而是继续进入既有阈值尾码或裸前缀逻辑；其他 SNR 区间完全保持 V152。

固定 seed1176/1177/1178 final 为 `63.075611/63.314250/63.252050`，均值 **`63.213970`**，相对 V152 提升 **`0.000116`**。seed2100/2101/2102 外部验证分别为 `0/0/+0.000015`，冻结后的 seed2103/2104/2105 新盲测分别为 `+0.000091/0/0`；九条 seed 均无负增益且 P10 不变。

详见 [V153 超高中间 SNR 输出扩展子区间](../experiments/extension-ultrahigh-middle-v153.md)。
