# FATE-MIMO V152：高中间 SNR 扩展门控专家

版本：V152，2026-08-25

V152 在 V149 的配对 RZF、Receiver 协方差、软干扰抵消和数据增益温度专家之上，重校准 `[-5,-2.5) dB` 的中间输出策略：924→1056 bit 扩展继续使用截断平均绝对 LLR 置信度，但门槛由 `0.260` 提高到 `0.296287667183649`。低一致性扩展不再提前返回 1056 bit，而是继续进入既有阈值尾码或裸前缀逻辑。

门槛由 V149 相对、五 seed、每 seed 前后两半共十块的稳健搜索选出，要求所有 seed 与半块均不退化。固定 seed1176/1177/1178 final 为 `63.075535/63.313977/63.252050`，均值 **`63.213854`**，相对 V149 提升 **`0.000354`**。冻结后的 seed2100/2101/2102 盲测分别提升 `0.000137/0.000243/0.000349`；固定与盲测六条 P10 均不变。

详见 [V152 高中间 SNR 输出扩展稳健重校准](../experiments/extension-highbin-threshold-v152.md)。
