# FATE-MIMO V190：安全 Wiener 与置信度 IC 组合

版本：V190，2026-08-27

V190 保留 V189 的弱用户保护双 UE Wiener 专家，并在单 UE `[10,20) dB` 内根据另一用户符号 posterior 置信度，以 `-0.1` gain 轻微降低软干扰抵消强度。发送端保护门消除了原 V175 的 P10 风险，接收端因子提供稳定的小均值增益。

固定 seed1176/1177/1178 final 为 `63.079409/63.318701/63.255741`，均值 **`63.217950`**，相对 V189 提升 **`0.000901`**。冻结后 seed2140/2141/2142 分别提升 `+0.001367/+0.001230/+0.001367`，所有 P10 均不变。
