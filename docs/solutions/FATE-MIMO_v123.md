# FATE-MIMO V123：低相关 Walsh 尾部码本

版本：V123，2026-08-24

V123 完整保留 V122 的反馈、预编码、调制、SNR 分段 Receiver、
`1/31` 控制预算与 `-2.5 dB` 匹配前缀策略，仅替换弱用户 228-bit
尾部 VQ 码本：

- 取 Walsh/Hadamard 连续行组，起始行 `65`；
- 16 个基础方向按相邻模板成对取反，截取为 31 个控制码字；
- 相比伪随机哈希模板，方向间相关性更低；
- 不增加权重、控制 bit、计算分支或提交包依赖。
