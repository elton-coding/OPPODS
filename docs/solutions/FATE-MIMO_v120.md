# FATE-MIMO V120：扩展弱用户尾部恢复区间

版本：V120，2026-08-24

V120 保留 V119 的全部链路，仅将 924-bit 中档输出与弱用户阈值尾部 VQ 的 SNR 分界从 `-9.5 dB` 上移到 `-8.0 dB`。这使更多中低 SNR UE 使用评分更稳定的 924-bit 前缀和控制尾部模板。

没有新增权重或推理计算，P10 三组均保持。完整搜索见 [中低 SNR 输出策略扫描](../experiments/snr-output-policy-sweep.md)。
