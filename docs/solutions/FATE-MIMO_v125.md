# FATE-MIMO V125：SNR 分箱截断置信度前缀专家

版本：V125，2026-08-24

V125 保留 V124 的任务导向反馈、鲁棒 RZF、分层 Gray 256-QAM、SNR Receiver 专家、`1/31` 控制预算、`-2.5 dB` 匹配前缀和 Walsh 尾部码本。唯一算法增量是将 924–1055 位扩展段的置信度改为上限 1.0 的绝对 LLR 截断均值，并对 `[-20,-2.5) dB` 的七个 2.5 dB 区间分别设置门限。

截断可降低少数极大 LLR 对均值的支配，使门控更关注整段 132 位是否普遍可靠。门限通过时输出 1056 位，否则保持 924 位或 Walsh 尾部回退路径，不新增权重、控制 bit 或依赖。
