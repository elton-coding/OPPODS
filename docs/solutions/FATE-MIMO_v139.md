# FATE-MIMO V139：超峰值双用户 SNR RZF 专家

版本：V139，2026-08-25

V139 在 V138 上新增双 UE SNR 均处于 `[16.75,20) dB` 时使用 `8.0` 的共享 RZF 正则子专家。固定三 seed final 为 `63.068502/63.301383/63.244940`，均值 **`63.204942`**，相对 V138 提升 **`0.000294`**；冻结后三条盲测全部为正且 P10 不变。详见 [V139 超峰值双用户 SNR RZF 专家](../experiments/paired-rzf-ultrapeak-v139.md)。
