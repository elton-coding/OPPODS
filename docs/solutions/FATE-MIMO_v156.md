# FATE-MIMO V156：内部上中间 SNR 扩展专家

版本：V156，2026-08-25

V156 在 V153 的两级高中间 SNR 门控之上，为 `[-3.95,-3.4) dB` 增加 `mean_clipped_1p0 >= 0.55` 的精细输出专家。这个内部区间由多个 seed 的正负变化边界共同确定：保留中部稳定正样本，同时排除 `-3.986 dB` 和 `-3.274 dB` 两端的已观察负样本。

固定 seed1176/1177/1178 final 为 `63.075778/63.314250/63.252050`，均值 **`63.214026`**，相对 V153 提升 **`0.000056`**。seed2100–2105 六条验证均非负，冻结后的 seed2106/2107/2108 新盲测分别为 `0/+0.000122/0`；所有 P10 均不变。
