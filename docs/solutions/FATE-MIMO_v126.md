# FATE-MIMO V126：回退语义驱动的裸前缀扩展

版本：V126，2026-08-24

V126 保留 V125 的任务导向反馈、鲁棒 RZF、分层 Gray 256-QAM、SNR Receiver 专家、Walsh 尾部码本和 2.5 dB 分箱截断置信度门控。新增规则只处理原逻辑最终返回裸 924 位的用户：若 UE SNR 不低于 `-7.5 dB`，则返回 1056 位物理 LLR；若已经选择 1056 位置信度扩展或 1152 位 Walsh 尾部，则保持原输出。

这将控制码字语义与 SNR 专家结合起来：高一些的中档 SNR 中，裸物理扩展平均有利；更低 SNR 仍依靠缺失位中性计分或 Walsh 尾部，保护 P10。不新增权重、控制 bit 或依赖。
