# FATE-MIMO V147：SNR 分段软干扰抵消专家

版本：V147，2026-08-25

V147 在 V143 的低中/高 SNR 配对 RZF 与 Receiver 协方差专家之上，把 Receiver 软干扰抵消基础强度从单一 `0.2` 扩展为三个逐 UE SNR 专家：`[-7.75,-5) dB`、`[-0.25,2.75) dB`、`[8,18) dB` 使用 `0.25`，其余区间保持 `0.2`。原有 SNR 斜率、最低启用门限与禁用微区间不变。

固定 seed1176/1177/1178 final 为 `63.075398/63.313081/63.250683`，均值 **`63.213054`**，相对 V143 提升 **`0.002537`**。冻结后的 seed2098/2099/2100 盲测分别提升 `0.002309/0.003919/0.000030`；固定与盲测六条 P10 均不变。

详见 [V147 Receiver 干扰抵消强度 SNR 专家](../experiments/receiver-ic-scale-v147.md)。
