# FATE-MIMO V131：超高 SNR RZF 强正则专家

版本：V131，2026-08-25

V131 延续 V130 的双 UE 多区间 RZF，只将两个 UE 均至少 `4 dB` 时的正则从 `1.20` 提高为 `1.80`。固定 seed1176/1177/1178 final 为 `63.043649/63.281939/63.222792`，均值 **`63.182793`**，相对 V130 提升 **`0.006578`**；冻结后三条盲测全部为正且 P10 不变。详见 [V131 超高 SNR RZF 强正则实验](../experiments/paired-rzf-ultrahigh-v131.md)。
