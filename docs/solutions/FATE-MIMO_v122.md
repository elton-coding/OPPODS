# FATE-MIMO V122：SNR 分段匹配前缀

版本：V122，2026-08-24

V122 保留 V121 的任务导向反馈、鲁棒 RZF、分层 Gray 256-QAM、SNR
Receiver 专家和 `1/31` 控制码字分配，只调整一个发送/接收联合策略：

- 将 924-bit 中档前缀及弱用户尾部 VQ 的共同边界从 `-8.0 dB` 扩展到
  `-2.5 dB`；
- `[-10,-2.5)` 获得稳定正收益；
- 在 `-2.5 dB` 截止，避免 `[-2.5,0)` 中继续使用中档策略造成的负收益；
- 发送端和接收端严格共享同一边界，避免控制尾部语义失配。
