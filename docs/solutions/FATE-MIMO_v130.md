# FATE-MIMO V130：极高 SNR RZF 子专家

版本：V130，2026-08-24

V130 将共享导频 RZF 进一步按双 UE SNR 细分：任一 UE 位于 `[-10,-2.75) dB` 时使用 `0.40`；两个 UE 都位于 `[-0.75,4.0) dB` 时使用 `0.90`；两个 UE 都至少为 `4.0 dB` 时使用 `1.20`；其余组合使用 `0.45`。

固定 seed1176/1177/1178 的 final 为 `63.035142/63.276698/63.216807`，均值 **`63.176216`**，相对 V129 提升 **`0.005271`**。冻结后 seed2041/2042/2043 分别提升 `0.005955/0.003114/0.003767`，六条 P10 均不变。详见 [V130 极高 SNR RZF 子专家实验](../experiments/paired-rzf-high-subband-v130.md)。
