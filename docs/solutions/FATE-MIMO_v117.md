# FATE-MIMO V117：弱用户控制语义与低 SNR 尾部恢复

版本：V117，2026-08-22

## 1. 版本结论

V117 保留 V115 的任务导向反馈、残差 Wiener 去噪、鲁棒 RZF、分层 Gray 256-QAM、正交保留导频和 27 级阈值尾部码本，只改变共享 5-bit 控制语义的服务对象，并重新标定低 SNR 输出策略。

三个固定 seed 的官方兼容评测平均 final 从 V115 的 `62.827437` 提升到 **`63.077458`**，增益 **`+0.250021`**。该提升同时来自 efficiency 和 P10，不是单 seed 或单指标交换。

## 2. 相对 V115 的改动

### 2.1 阈值尾部 VQ 服务瞬时弱用户

V115 在非双高 SNR 场景中，从 27 个合法阈值索引中选择最匹配瞬时强用户未发送尾部的模板。V117 改为：

1. 根据两用户下行 SNR 取得 `argmin(SNR)` 的瞬时弱用户；
2. 从该用户实际未输出的尾部位置提取目标 bit；
3. 仍只在两用户 SNR 之间的合法阈值中搜索最佳模板；
4. Receiver 以 `snr <= threshold` 判断自己是否是本次模板服务对象。

没有增加控制比特、反馈符号、模型权重或推理接口。

### 2.2 取消 1-bit 保护分支

V115 在 `SNR < -15.5 dB` 时只输出 1 bit，导致 P10 被离散地锁在 `49.956597`。弱用户尾部 VQ 生效后，重新 sweep 得到 `LOW_SNR_THRESHOLD_DB=-20.0`，即赛题采样范围内始终至少输出 924 bit。

这项改动使 seed 1176：

- efficiency：`68.133659 -> 68.242752`；
- P10：`49.956597 -> 50.607639`；
- final：`62.680540 -> 62.952218`。

## 4. 与 2025 获奖方案的关系

去年冠军强调控制比特应承载 Receiver 无法从本地观测恢复的“控制语义”，并使用 SNR 分段与评分代理目标。V117 没有复制其单用户专家网络，而是把这一思想迁移到今年的 MU-MIMO：共享控制字优先补偿瞬时弱用户的不可观测尾部，并用 exact P10 重新决定低 SNR profile。
