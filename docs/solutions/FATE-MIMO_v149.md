# FATE-MIMO V149：SNR 分段数据增益温度专家

版本：V149，2026-08-25

V149 在 V147 的配对 RZF、Receiver 协方差与软干扰抵消专家之上，新增逐 UE 数据增益细化温度专家：`[10.5,15.75) dB` 将后验温度从 `0.5` 调整为 `0.6`，其他区间保持不变。更软的中高 SNR 后验降低了数据增益迭代中偶发硬判决抖动，而不改变输出长度与公平尾部。

固定 seed1176/1177/1178 final 为 `63.075535/63.313658/63.251305`，均值 **`63.213499`**，相对 V147 提升 **`0.000446`**。冻结后的 seed2098/2099/2100 盲测分别提升 `0.000987/0.000608/0.000911`；固定与盲测六条 P10 均不变。
