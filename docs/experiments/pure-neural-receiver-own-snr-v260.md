# V260：只改变接收端的SNR专家路由

2026-09-10预登记。分支codex/pure-neural-receiver-own-snr-v260从4151b4a创建。主干仍V250本地68.60602864583332、线上未知；V256温度减半完整负结果已否决。现有V257/V258继续训练，V259继续等待。本实验尚无训练、成绩或CPU证明；先登记并推送假设和设计，再运行独立CPU证明。不修改已冻结生产文件。

## 唯一因素

当前八个Tx专家按pair-min-SNR的5dB区间工作，Rx用控制位直接选择同编号专家。V260保留Tx/Encoder及控制位逐字节逻辑，只把八个Rx专家改为“保持原V227父组，再按自身SNR分工”。两组定义由原父模型边界-10dB决定，不从新候选分数搜索：

| Tx控制编号/原父组 | 自身SNR | Rx编号 |
|---|---|---|
| 0或1（pair-min<-10） | [-20,-10) | 0 |
| 0或1（pair-min<-10） | [-10,20] | 1 |
| 2至7（pair-min>=-10） | [-10,-5)、[-5,0)、[0,5)、[5,10)、[10,15)、[15,20] | 2至7 |

发送方与接收方的父映射都仍为[0,0,1,1,1,1,1,1]，所以初始每次选择的Rx父权重与V250对应父组相同，无需改训练入口或初始化映射。八个Rx仍独立，数量/宽512/深10/190354976总参数/189551584可训练参数均不变；不引入控制嵌入、物理模块、共享前层、Encoder解冻或新温度。

对独立均匀[-20,20]的两UE SNR，按UE计数的Rx路由概率为[1/4,3/16,3/32,3/32,3/32,3/32,3/32,3/32]；原pair-min路由为[15,13,11,9,7,5,3,1]/64。这里是给定分布下的解析概率，不是用测试集拟合采样比例。训练仍原分布，不重采样。该单因素同时改变Rx条件信息的分区方式、分区分辨率和各专家曝光量，不能分别作因果归因。

假设：Rx按自身噪声条件分工、减少极稀疏专家可能改善当前八专家长训练。风险：同一Rx开始接收多个Tx专家生成的信号，而ReceiverCore仍不额外读取Tx控制嵌入；这种混合可能更难学习。此外低父组的弱UE从两个5dB min区间合为一个自身10dB区间，可能损害尾部表现。必须完整训练比较，不能由初始等价或更均衡概率推断提升。

仍原V227 fresh初始化，不从V250或探针续训；原RMS T0.5/公平0.3/带宽0.025/BCE0.05、Adam1e-5、batch100、72000步、验证2000每1000步、patience72、seed15240、完整1152位/k8、Encoder冻结、FP32/cap0.4不变。唯一命令变化model-design和output-dir；来源、控制和实际结构单独哈希绑定。
