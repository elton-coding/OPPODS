# V233：5bit内的配对SNR控制（已完成，未晋级）

问题：V227控制字段只用了两个码字表示低/高模式，接收机不知道另一UE的SNR。历史V222只传最大SNR：当接收机自身较强时，最大值就是自身，不能提供弱伙伴的信息。该历史实验未提高分数，因此本次不是原方案重试。

新编码：bit0保持V227的联合专家选择；另外4bit量化两UE的SNR之和[-40,40]，每档5dB。接收机减去已知自身SNR，得到误差不超过2.5dB的伙伴SNR估计（边界裁剪）。一层零初始化的1→512线性嵌入加入Receiver。Tx/Rx路由仍仅由bit0决定，避免其他4bit误选专家。控制字段只来自SNR，不携带数据bits。

保持纯神经数据链路；未增加上行资源、控制bit数或物理算法。初始权重严格继承V227，新增投影为零，因此初始输出保持一致。该方法只有1024个新增参数，不改变B1152/k8或专家数量。

对照复用V230两专家续训：V227初始化映射[0,1]，Encoder冻结，全部Tx/Rx训练；seed15240、batch100、Adam1e-5、12000步、每1000步验证2000通道，soft_score温度0.5及其他参数不变。输出 `artifacts/pure_neural_v233/partner`。

固定validation选点，audit配对复评，若达到69再用新留出窗口复核。单列均值、P10和各SNR区间，不能把控制信息的理论可用性当作实测收益。

## 完整训练及配对结果

完成12000步，最佳检查点12000步，validation总分68.214678，效率73.788826、P10为55.208332。训练耗时1899.9秒（并行运行，不据此推断模型加速）。固定split1176、test offset2000逐样本评测：

均分 **68.334231**。相对同预算V230C为+0.020332，但信道聚类配对bootstrap 95%区间[-0.005338,0.050514]跨0，尚不能认定可靠方法收益；相对当前冠军V230E为-0.026233，区间[-0.053558,0.008018]。不晋级，不默认加入组合池。

不能直接和八专家叠加：当前编码消耗1个模式bit+4个SNR和bit，而八专家需要3个模式bit，直接组合会超过5bit控制预算；八专家最低SNR分箱还可能与伙伴信息存在重叠。若今后提出压缩控制方案，必须视为新实验，不能相加历史增益。
