# V255：固定前缀后的余弦学习率衰减

2026-09-09预登记；特性分支codex/pure-neural-cosine-v255，从ec9126a创建，保留正在运行的V253/V254及存储四组等待器的所有冻结代码。当前main仍V250本地固定68.60602864583332，线上未知，目标未达成。

## 假设与唯一因子

去年视频精读的“下午一点半”使用Lion和cosine annealing，但其数据、损失、架构和预算均不同，不能把报告的70+直接迁移为今年收益。当前V250将36k延长至72k得到稳定但有限的本地提升，仍全程固定Adam学习率1e-5。检验在相同72k预算下，后半程缩小更新幅度是否改善验证最佳权重与固定硬判决总分。

仅改变学习率时间表，不同时更换优化器、损失、专家数、路由、batch或训练预算。第1至36000次成功Adam更新使用1e-5；第36001至72000次按`lr=1e-5*(0.1+0.9*(1+cos(pi*(update-36000)/36000))/2)`衰减，最后1e-6。没有重启、没有另行warmup。起点、拐点、终点本次固定，不能见test后调度或选终点。过早/过强衰减可能降低探索和后期收益，该试验允许失败。

仍从原V227独立初始化八个5dB联合Tx/Rx专家，父映射[0,0,1,1,1,1,1,1]；不是从V250或36k最佳checkpoint恢复。fresh Adam、宽512×10、Encoder冻结、batch100、seed15240、完整72k、patience72、每1000步固定2000验证信道、B1152/k8、RMS/T0.5/公平0.3/带宽0.025/BCE0.05及GPU分配上限0.4都沿用V250。训练数据split1176和原抽样/随机流不变。

## 实现和验证门控

独立入口scripts/train_pure_neural_cosine_v255.py只在当前进程给原Adam附加step前/后钩子，不修改共享RMS/基线训练器；优化器状态延续、不引入随机数。逐次成功更新的实际学习率以float64小端序SHA256绑定，并保存边界/每1000步轨迹。learning_rate字段只代表初始值，learning_rate_schedule记录实际时间表；缺失完整更新数/哈希/轨迹则不能审计。两步资源探针使用完整72k时间表的前两步，不压缩成两步衰减。

先用CPU小参数实跑72k次原Adam和带钩子的Adam：前36000次参数与所有优化器状态逐次相同，后半程带钩子版本与手动按公式设置lr的独立参考一致，完整RNG状态一致。此为实现证据，不是模型成绩。再等V253完整审计释放名额，执行原模型两步/验证2000探针核对初始指标，再从原V227全新72k；最多两项GPU重任务，不占第三项。完整37个0..36k验证点与V250前缀核对，不把该指标证明说成真实模型优化器逐位证明。

预留正式目录artifacts/pure_neural_v255/eight/cosine_steps72000，探针artifacts/resource_probe/v255/eight_cosine，标签v255_eight_rms_cosine_72k；CPU证据benchmarks/v255_cosine_cpu_proof.json。此预登记时仅独立入口/专项测试已编写，CPU72k证明及训练队列尚未实现/启动，不存在V255训练。
