# V187：置信度自适应干扰抵消（拒绝晋级）

## 结论

V187 在接收端用另一用户符号后验的最大概率作为置信度，按符号降低高置信度场景下的干扰抵消强度。六个发现种子和十二个时间块全部为正，但冻结后的三个新盲测种子中 seed 2130 退化 `-0.000182`。按照预先声明的“每个盲种子总分均不得下降、P10 不得下降”门禁，本版本不合并 `main`，冠军继续为 V156。

## 方法

- 置信度：`(max(posterior) - 0.1) / 0.9`，截断到 `[0, 1]`。
- 候选增益：`-0.10/-0.05/+0.05/+0.10`。
- 负增益表示在另一用户判决更可信时适度降低抵消比例，减少过度抵消。
- 首轮从完整 `[-20, 20] dB` 范围按 `0.25 dB` 网格搜索连续区间。
- 最终冻结策略只在 `10.0 <= SNR < 20.0 dB` 使用增益 `-0.10`，其余 SNR 完全保持 V156 行为。
