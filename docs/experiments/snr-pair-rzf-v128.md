# V128 双 UE SNR 分段 RZF 专家实验

日期：2026-08-24  
分支：`codex/snr-receiver-profiles-v128`  
对照：V127

## 方法

保留 V127 的 Receiver、输出长度和 Walsh 尾部策略，只调整保留导频链路的共享 RZF 正则。由于预编码器同时服务两个 UE，路由条件不能只看单个 UE：当任一 UE 的下行 SNR 落在 `[-10,-2.75) dB` 时，将 `PILOT_RZF_REGULARIZATION` 从 `0.45` 降为 `0.40`；其余 SNR 组合仍使用 `0.45`。

全局使用 `0.40` 时，固定三 seed 的 final 分别回退 `0.002628/0.001519/0.006699`。逐 UE 配对分桶后发现，负迁移集中在高 SNR，而 `[-10,-2.5) dB` 明显为正；按双 UE SNR 路由后，三个固定 seed 同时转正。这说明共享链路参数也必须使用 SNR 专家，而不能由全局均分决定。

## 参数与边界筛选

- `0.425` 在 1000 样本三 seed 上全部低于 `0.40`；
- `0.375/0.350/0.325/0.300` 的 efficiency 一度更高，但更低正则开始触发 P10 离散下跳；
- `0.325` 在固定 2000×3 上均值提升约 `0.01067`，但冻结后 seed2031 的 P10 下跳 `0.086803`，final 回退 `0.016349`，因此否决；
- 回到 `0.40` 后，seed2029/2030/2031 相对 V127 分别提升约 `0.006639/0.005226/0.001042`；
- `[-10,-2.75)` 是固定三 seed 上唯一同时优于 `[-10,-2.5)` 的 0.25 dB 边界，随后冻结。

三个固定 seed 的 P10 均与 V127 相同，增益全部来自 efficiency。
