# V123 Walsh 行步长扫描

日期：2026-08-24  
分支：`feature/walsh-lattice-v123`  
对照：V123（start65、step1）

为避免逐行手工选择造成过拟合，增加结构化
`THRESHOLD_WALSH_STEP`：第 `i` 个基础模板使用
`(65 + step*i) mod 256` 行。默认 step1 与 V123 精确一致。

seed1176、300 样本扫描 step
`2/3/4/5/7/8/11/13/15/16/17/31`。V123 step1 为 `62.420218`，所有
候选仅为 `62.308500–62.369900`，且多数 P10 下降。

结论：连续行组关系优于稀疏等步长抽样，没有候选进入多 seed。步长接口
保留在特性分支用于研究，不合入 `main`。
