# V175 双 UE 联合 SNR Wiener 去噪尺度专家（拒绝）

日期：2026-08-25  
分支：`codex/paired-wiener-scale-v175`  
对照：V156

## 方法

发送端反馈去噪器原先全局使用 `WIENER_NOISE_SCALE=0.75`。全局粗扫曾显示
`0.625/0.875` 均退化，但该参数只影响共享预编码器，因此本轮把同一信道
样本的两个 UE 绑定，分别搜索 `any-user/all-user` 联合 SNR 区间。门禁使用
六个发现 seed、每 seed 2000 样本、十二个按信道样本切分的半块，并要求
final 与 P10 全部非负。

冻结候选为：任一 UE 位于 `[2.75,11.25) dB` 时，两个 UE 的反馈去噪均将
尺度从 `0.75` 调为 `0.875`；其他样本保持 V156。

真实路由在 seed1176 的 500 和 2000 样本上，分别与全局反事实按
`data_index` 拼接后的 1000/4000 个逐 UE score 和输出长度完全一致，均为
0 mismatch。52 项测试和 Ruff 均通过。

## 结论

- V175 不晋级，不生成正式提交包，不合并模型代码到 `main`。
- 共享反馈去噪尺度确有约百分位的均值信号，但当前候选对 P10 排序不够平滑。
- 后续优先搜索不改变发送端整体波形的 Receiver 连续参数；若重启共享链路
  参数，必须加入更直接的尾部分位安全约束，而不能围绕本次盲测修边界。
