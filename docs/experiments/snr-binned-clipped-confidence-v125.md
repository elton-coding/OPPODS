# V125 SNR 分箱截断置信度门控

日期：2026-08-24  
分支：`feature/snr-binned-clipped-confidence-v125`  
对照：V124

## 方法

对 V124 的 bit 924–1055 扩展段绝对 LLR 进行截断均值：

```text
confidence = mean(clamp(abs(extension_llr), max=1.0))
```

将 `[-20, -2.5) dB` 按 2.5 dB 划分为 7 个区间，每个区间独立使用门限：

| SNR 区间 dB | 门限 |
|---|---:|
| [-20.0, -17.5) | 0.246 |
| [-17.5, -15.0) | 0.246 |
| [-15.0, -12.5) | 0.246 |
| [-12.5, -10.0) | 0.124 |
| [-10.0, -7.5) | 0.101 |
| [-7.5, -5.0) | 0.246 |
| [-5.0, -2.5) | 0.246 |

门限通过时输出 1056 位，否则沿用 V124 的 924 位/Walsh 尾部回退路径。

## 未见种子验证

门限冻结后，在未参与搜索的三个种子上分别跑 V124/V125 配对评测：

| seed | V124 final | V125 final | delta |
|---:|---:|---:|---:|
| 2026 | 63.031598 | 63.031887 | +0.000289 |
| 2027 | 63.125855 | 63.126053 | +0.000197 |
| 2028 | 62.854783 | 62.855360 | +0.000577 |
| 均值增益 | — | — | **+0.000354** |

六个种子的 P10 均未变化，最终分增益全部来自效率。未见数据的 `[-10,-7.5) dB` 配对均值略负，后续应在独立特性分支上尝试收紧该区间，不能直接覆盖本稳定版本。

## 决策

V125 在三个固定种子与三个未见种子上均优于 V124，且没有公平性回退，晋级为稳定候选。
