# V240：同轨迹训练预算12k→36k（预登记）

## 为什么转向预算

V230C/E的完整12k续训曾可靠提高分数，但V231—V238多个温度、条件信息、载荷、宽度和学习率改动未超过E。V237八专家提高学习率甚至以起点为最佳。下一项检验在原来有效的1e-5下增加训练预算，而不是继续提高步幅或默认叠加负特性。

## 严格嵌套而非假续训

原训练没有保存完整Adam与随机数恢复点。因此本次不从best权重加载新Adam后声称精确续训，而是两专家和八专家均从相同V227父模型重新执行原来的前12000步，再在同一个训练进程中继续至36000步。前12k重跑是保证预算消融可解释的成本。

两专家沿用V227设计、映射[0,1]；八专家沿用V230设计、映射[0,0,1,1,1,1,1,1]。Encoder冻结，全部Tx/Rx训练。seed15240、batch100、Adam1e-5、validation2000每1000步、soft_score T0.5/P10权重0.3/tail_fraction0.1/带宽0.025/BCE0.05、全SNR独立均匀、FP32、GPU上限0.4全部不变。仅steps=36000及相应patience=36，以完成注册预算。

两组分别和已完成12k的C/E比较训练预算增量，再比较同一36k预算的两/八专家，不能把增加样本次数的收益全归于专家数量。最高validation选点仍可保留起点或前12k检查点；若长训不提高，则如实报告。

运行器scripts/run_pure_neural_budget_v240.py保存输入哈希和命令，输出分离为artifacts/pure_neural_v240/two/steps36000与eight/steps36000。训练结束核对0—12000步的13次验证轨迹：BCE误差≤1e-5，效率/P10/总分误差≤1e-4。若不匹配，停止自动audit先调查，不能将不同轨迹包装为单预算差异；此检查也不等同于证明全部Adam状态逐位相等。
