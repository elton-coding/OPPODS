# V122 中档前缀长度复扫

日期：2026-08-24  
分支：`feature/middle-prefix-length-v122`  
对照：V122（924 bit）

V122 把中档策略覆盖范围扩展到 `[-10,-2.5)` 后，使用 seed1176、300
样本，以 132 bit 整组粒度复扫 `MIDDLE_PREFIX_BITS`：

| 前缀 bit | efficiency | P10 | final |
|---:|---:|---:|---:|
| 132 | 66.321253 | 50.694444 | 61.633210 |
| 264 | 66.739366 | 50.694444 | 61.925890 |
| 396 | 66.956670 | 50.520833 | 62.025919 |
| 528 | 67.202040 | 50.520833 | 62.197678 |
| 660 | 67.290871 | 50.520833 | 62.259860 |
| 792 | 67.409939 | 50.607639 | 62.369249 |
| **924（V122）** | **67.409939** | **50.694444** | **62.395291** |

短于 924 bit 的候选全部退化。尤其 792 bit 的 efficiency 与 V122
相同，但 P10 下降一个台阶，最终分低 `0.026042`。保留 924 bit，不进入
多 seed 复验。
