## 连续边界

使用 V125/V126 的六种子完整配对归档，将裸 924 位扩展下界从 `-7.5 dB` 向上以 0.25 dB 扫描。六种子平均增益在 `-7.5 dB` 最大；提高边界会稳定损失，因此保留 V126 边界。

向下扩展到 `[-10,-7.5)` 的逐前缀诊断中，整体 1056 位扩展在 seed1177/1178 为负。唯一在三个固定种子的前 1000 样本上均为正的细组合是：`[-8.5,-8.0)` 裸 924 位用户扩展到 979 位。
