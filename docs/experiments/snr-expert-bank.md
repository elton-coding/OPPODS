# 离散 SNR 专家银行实验

日期：2026-08-23  
原始分支：`feature/snr-expert-bank`  
对照：V117

## 背景

2025 年多个获奖队伍把 `[-20,20] dB` 划成多个区间，为每个区间独立训练参数。本实验补齐离散专家训练、推理路由、打包、逐专家消融和多 seed exact 复评。

## 第一阶段：8 个 5 dB 专家

初始区间为：

`[-20,-15)、[-15,-10)、[-10,-5)、[-5,0)、[0,5)、[5,10)、[10,15)、[15,20]`

每个专家从 V117 去噪器权重独立训练 750 step，使用本区间 SNR 采样和验证集。推理时根据每个 UE 的 SNR 只执行命中的专家，因此参数量增加但单次去噪计算量不乘 8。复制八套 V117 权重时，seed1176/500 样本 exact score 与 V117 完全一致；八专家 ZIP 约 18 MB。

### 单专家消融

| 区间 | final | 相对 V117 |
| --- | ---: | ---: |
| `[-20,-15)` | 62.649661 | -0.050868 |
| `[-15,-10)` | 62.675877 | -0.024653 |
| `[-10,-5)` | 62.768030 | +0.067500 |
| `[-5,0)` | 62.686250 | -0.014280 |
| `[0,5)` | 62.693906 | -0.006623 |
| `[5,10)` | 62.707196 | +0.006667 |
| `[10,15)` | 62.712535 | +0.012005 |
| `[15,20]` | 62.720078 | +0.019549 |

同时启用全部专家时 final 为 `62.642674`，低于 V117，但 P10 提升到 `50.954861`。这证明分区训练确实能改变公平尾部，也证明正负区间不能无筛选组合。

### `[-10,-5)` 粗专家长评

| seed | V117 | 专家候选 | 增益 |
| ---: | ---: | ---: | ---: |
| 1176 | 62.952218 | 62.974750 | +0.022533 |
| 1177 | 63.155982 | 63.146184 | -0.009798 |
| 1178 | 63.124175 | 63.139933 | +0.015757 |

三 seed 平均约提升 `0.009497`，但 seed1177 回退。额外训练 seed2176/3176，并尝试参数平均和向 V117 插值，仍未消除该回退。

## 第二阶段：关键频段细分为 1 dB

逐 UE 配对诊断显示 seed1177 的 `[-10,-9.5]` 明显下降，而 `[-8.5,-8.0]` 上升，因此把关键带拆为 `[-10,-9)、[-9,-8)、[-8,-7)、[-7,-6)、[-6,-5)`，其余仍用 5 dB 分段。12 套复制权重继续与 V117 exact 一致，ZIP 约 27.1 MB。

五个 1 dB 专家各训练 750 step，seed1176/500 样本消融为：

| 区间 | final | 相对 V117 |
| --- | ---: | ---: |
| `[-10,-9)` | 62.754800 | +0.054271 |
| `[-9,-8)` | 62.725052 | +0.024523 |
| `[-8,-7)` | 62.689045 | -0.011484 |
| `[-7,-6)` | 62.691050 | -0.009479 |
| `[-6,-5)` | 62.731137 | +0.030608 |

短评最好的 `[-10,-9)` 在 seed1178/2000 样本为 `63.105627`，低于 V117 的 `63.124175`，因此没有晋级。

## 复现资产

- `modelSubmit/modelDesign.py`：按 UE SNR 路由独立去噪器；
- `scripts/train_precoder_aware_denoiser.py`：支持区间训练；
- `scripts/bundle_snr_experts.py`：校验并打包独立专家权重；
- `scripts/evaluate_submission.py --scores-out`：导出逐 UE exact score/SNR；
- `scripts/interpolate_denoiser_checkpoints.py`：专家权重插值与参数平均。

原始训练代码保存在远端分支 `feature/snr-expert-bank`；检查点和候选包位于 Git 忽略的 `checkpoints/`、`artifacts/candidates/`。

## 结论

1. 离散 SNR 专家路线有效，但“全部专家一起启用”不是可靠组合方法。
2. 5 dB 粗专家能显著改变 P10，必须逐段筛除 efficiency 负迁移。
3. `[-10,-5] dB` 最有研究价值，1 dB 细分确实分离出正负区间，但当前训练目标与 exact final 的相关性不足。
4. 若重启该路线，应按消融模板分别评测每个专家，并用 C/A/B/AB 验证多个专家的交互；不能根据单 seed 短评直接拼接。
