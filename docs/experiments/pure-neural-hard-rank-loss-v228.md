# V228：真实硬判决排名 + 平滑替代梯度（预登记）

## 单因素对照

两组均从同一 V224 权重初始化，使用原单模型、B1152/k8、全部模块训练。seed=15234、batch=100、Adam lr=5e-6、6000 步、每750步验证、2000验证通道、patience=8。T=0.5、带宽0.025、BCE权重0.05、公平权重0.3、分位0.1不变。

- control：原 soft_score，按软正确率排名。
- treatment：hard_rank_score，按真实逐UE硬判决正确率排名。

两组初始权重、样本序列、噪声、验证集、预算相同，唯一训练目标区别是排名/前向分数定义。固定验证选择各自最佳 checkpoint，并报告同一步结果，避免只挑各自峰值解释。

## 目标的定义与限制

前向 bit 正确率使用官方 `(logit>=0)==bit`；反向借用 sigmoid(signed_logit/0.5) 梯度（straight-through estimator）。UE 真实正确率排序后，前向取精确线性插值 P10，反向保留 P10 附近高斯排名加权梯度。加0.05 BCE保持与对照一致。

这样，去掉 BCE 后的前向损失值精确等于该 batch 的负评分，但反向是**有偏替代梯度**，不是不可导硬评分的数学导数；不能保证真实分数单调升高。保留平滑尾部梯度是为了避免只更新两条位于精确分位点的样本。

## 验证

单元测试涵盖 logit=0、target=0/1、短输出0.5补偿、前向与官方公式一致、梯度有限且方向正确、软/硬排名不同时梯度确有变化。候选仅通过固定留出集新协议配对复评后才考虑晋级。
