# V229：联合SNR专家 × 硬排名损失，2×2消融预登记

## 假设和四组

硬排名可能修复V227的弱用户损失，同时保留联合收发适应对强用户的收益。也可能两者互相抵消，故不能直接相加历史收益。

| 组 | 联合低SNR专门化方法A | 硬排名损失B | 实验文件夹 |
|---|---:|---:|---|
| C | 否 | 否 | `pure_neural_v228/soft_score` |
| A | 是 | 否 | `pure_neural_v227/joint_low` |
| B | 否 | 是 | `pure_neural_v228/hard_rank_score` |
| AB | 是 | 是 | `pure_neural_v229/joint_hard` |

A是一个方法级因子：复制两个联合Tx/Rx专家、-10dB固定分界、冻结共享Encoder及高模式、只优化低模式。它包含上述配套机制，不宣称已经分离专家数量、冻结策略、训练参数量各自的独立贡献。B仅改变评分损失中的硬/软排名与前向计分。

四组均从未改变的V224权重重新初始化；AB不是在已经训练好的V227上多训6000步。seed15234、batch100、Adam5e-6、6000步、验证每750步、2000通道、全SNR独立均匀分布、T0.5、BCE0.05、带宽0.025、官方公平权重0.3完全一致。AB使用V227原modelDesign，无推理代码改动。

## 评测与门槛

固定验证集选检查点，报告同一步与各自最佳；按已登记固定留出集三噪声种子配对比较。计算A-C、B-C、AB-C、交互AB-A-B+C，同时报告P10与各SNR区间，收益不得相加。

本轮已查看留出集部分结果，因此它是audit集而非新盲测。不依据结果修改分界或损失参数。本轮以用户要求的最高官方总分筛选候选，明确披露P10退步，不将总分提高描述为弱用户保护成功。组合若不超过已确认候选，不替换主干。

分支从main创建，再合入已推送V227/V228的评测修复、训练器与实验记录作为依赖；模型初始化仍为V224。完整训练历史和逐UE结果保留在各版本目录。

## 完整结果与决策

AB完成6000步、最佳step4500；固定验证best67.930913、last67.911029。四组都从V224初始化，无额外续训预算。对应留出集均值如下：

| 组 | Final均值 | 相对等预算C |
|---|---:|---:|
| C 普通软评分续训 | 68.119797 | 0 |
| A 联合专家＋软评分 | **68.154844** | **+0.035048** |
| B 单模型＋硬排名 | 68.127341 | +0.007544 |
| AB 联合专家＋硬排名 | 68.143986 | +0.024189 |

AB三个噪声种子的Final为67.942693/68.206918/68.282346，均低于A。AB-A=-0.010859，配对95%区间[-0.041378,+0.007119]；不宣称显著退化，但没有证据支持替换A。交互项AB-A-B+C=-0.018403，区间[-0.055394,+0.009457]，不能确认正协同。

A相对等预算C的净收益+0.035048，配对95%区间[+0.018269,+0.067831]；A相对未继续训练V224的+0.084911包含普通续训收益，不能全部归因于分区方法。

结论：保留A即V227为总分最高候选，AB不晋级。本轮仍未达到69；P10代价见V227报告，不把总分提升称为所有SNR区间同时改善。选择门槛保持预登记的最高官方总分，不根据复评结果修改任何边界。

完整训练：`benchmarks/pure_neural_joint_hard_v229_training.json`；四组逐区间、P10、配对差及交互：`benchmarks/pure_neural_factorial_v227_v229.json`。已经查看的数据仅作为audit，不当作未来新候选的盲测。
