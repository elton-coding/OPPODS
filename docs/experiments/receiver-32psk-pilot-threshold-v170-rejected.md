# V170 32PSK 导频相位位起始阈值（拒绝）

日期：2026-08-25  
分支：`codex/receiver-32psk-pilot-threshold-v170`  
对照：V156

V156 从 `18.75 dB` 起把导频相位载荷由 4 位提高到 5 位。seed1176 前 500 样本扫描 `18.25/18.5/19.0/19.25 dB` 均为正，其中 `19.25` 最优。为区分 `[18.75,19.0)` 与 `[19.0,19.25)`，冻结并分别验证 `19.25` 和 `19.0`，不做连续边界重搜。

## 六 discovery seed 结果

| Seed | 阈值 19.25 增益 | 阈值 19.0 增益 |
|---:|---:|---:|
| 1176 | +0.000600 | -0.000061 |
| 1177 | -0.000319 | +0.000152 |
| 1178 | -0.001284 | -0.000600 |
| 2120 | +0.000068 | +0.000425 |
| 2121 | +0.024698 | +0.001025 |
| 2122 | -0.000934 | -0.000684 |

`19.25` 有三个常规负 seed，seed2121 的大正值含 P10 `+0.078123` 跳升。更窄的 `19.0` 在所有 seed 上 P10 不变，但仍为三正三负，无法证明 `[18.75,19.0)` 的第 5 位应删除。

结论：保持 `PILOT_32PSK_MIN_SNR_DB=18.75`。V170 在 6-seed discovery 阶段拒绝，不进入真正盲测、不修改模型、不构建包、不合并 `main`；冠军继续为 V156。
