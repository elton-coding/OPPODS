# V183 Receiver 导频增益插值尺度专家复扫（拒绝）

日期：2026-08-25  
分支：`codex/receiver-pilot-interpolation-v183`  
对照：V156

## 方法

V156 默认 `PILOT_GAIN_INTERPOLATION_SCALE=0.5`，并在 V119 已验证的
`[-17.5,-15)`、`[-10,-7.5)`、`[15,20)` 使用 `0.75`。本轮保留这些
既有专家，只改变默认值，扫描 `0.4/0.625/0.875` 并做逐 UE SNR 重组。

seed1176、500 样本中：

- `0.4` 在极低 SNR 段出现约 `+0.001458` 的局部信号；
- `0.875` 在 `[-2,2.25) dB` 出现约 `+0.002248` 的局部信号；
- `0.625` 的低 SNR 表观收益约 `+0.0283`，但主要来自单 seed P10
  `+0.0868` 跳档，因此按预先风险规则不扩样。

前两侧分别生成六个发现 seed、每 seed 2000 样本反事实，并使用六 seed、
十二半块和 P10 非退化门禁重新搜索连续区间。

## 六种子全局反事实增益

| Seed | 默认 0.4 | 默认 0.875 |
|---:|---:|---:|
| 1176 | -0.001641 | -0.028259 |
| 1177 | -0.002765 | -0.029931 |
| 1178 | -0.000699 | -0.002658 |
| 2120 | +0.001960 | +0.001367 |
| 2121 | -0.000851 | +0.028608 |
| 2122 | +0.001413 | -0.001291 |

`0.875` 的大幅正负主要对应 P10 离散跳档。两套逐 UE扫描均没有任何
正收益同时通过六 seed、十二半块和 P10 门禁的区间；顶部零增益结果来自
既有 `0.75` 专家覆盖、候选默认值未生效的区间。

## 结论

V183 不晋级，不实现新插值区间，不进入盲测。保留 V156 的默认 `0.5`
与三个既有 `0.75` 专家。
