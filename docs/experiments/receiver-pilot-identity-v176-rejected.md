# V176 Receiver 导频身份 margin/slope 细扫（拒绝）

日期：2026-08-25  
分支：`codex/receiver-pilot-identity-v176`  
对照：V156

## 方法与结果

在 seed1176、500 样本官方兼容 exact 评测上，保持其他参数不变，扫描
`PILOT_IDENTITY_MARGIN=0.275/0.325` 与
`PILOT_IDENTITY_MARGIN_SNR_SLOPE=-0.015/-0.025`。V156 final 为
`62.844883`。

| 候选 | final | 全局增益 | P10 变化 |
|---|---:|---:|---:|
| margin `0.275` | 62.831454 | -0.013429 | 0 |
| margin `0.325` | 62.843607 | -0.001276 | 0 |
| slope `-0.015` | 62.831454 | -0.013429 | 0 |
| slope `-0.025` | 62.843607 | -0.001276 | 0 |

保存逐 UE score 后，在 0.25 dB 网格上搜索最长 10 dB 的连续区间，并把
500 样本拆成前后两个块。四组扫描均没有任何“正收益且整体、两个半块与
P10 全部非负”的区间；输出顶部全是参数没有触发差异的零增益区间。

## 结论

- 不扩到六发现种子，不进入盲测，不修改模型代码。
- 保留 V156 的 margin `0.3` 与 slope `-0.02`。
- 两对候选在该随机流上产生完全相同的判决结果，说明可见变化来自少量
  identity gate 翻转，并没有可稳定路由的 SNR 子群。
