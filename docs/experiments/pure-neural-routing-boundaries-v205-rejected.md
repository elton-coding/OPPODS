# V205 V199 专家路由边界复扫（未采用）

## 方法

保持 V199 权重和输出前缀不变，扫描已训练专家 1/2 附近的硬 SNR 路由边界。先在 seed 1176 的前 1000 个信道样本上比较默认值及 `±0.5 dB` 候选，再对初筛最佳做完整 2000 样本复核。

## 1000 样本初筛

| 路由边界变化 | final | 相对默认 `62.362196` |
|---|---:|---:|
| 默认 `-15 / -10 dB` | `62.362196` | — |
| `-15 → -15.5 dB` | `62.361406` | `-0.000790` |
| `-15 → -14.5 dB` | `62.362591` | `+0.000395` |
| `-10 → -10.5 dB` | `62.384601` | `+0.022405` |
| `-10 → -9.5 dB` | `62.355421` | `-0.006775` |

`-10.5 dB` 的初筛提升来自 P10 离散档位变化。

## 完整复核

在 seed 1176 全部 2000 个信道样本上：

- V199 默认边界：`62.426223`；
- `-10 → -10.5 dB`：`62.425281`；
- 差值：`-0.000942`。

## 结论

1000 样本初筛的 P10 提升不能在完整评测中复现。保留原始 5 dB 固定路由边界，不采用 V205。当前纯神经最佳继续为 V199。
