# V194：纯神经 logits 置信度输出（拒绝）

- 日期：2026-08-29
- 分支：`codex/pure-neural-confidence-output-v194`
- 对照：V193 固定 SNR 前缀
- 状态：发现集净收益近零，拒绝

## 1. 假设与方法

V193 对同一低 SNR 区间采用固定 1/132/1152 输出长度。V194 不改变网络权重，保存完整 logits 的以下黑盒置信度：

- bit 2～132 的平均绝对 logit；
- bit 133～1152 的平均绝对 logit；
- 全扩展区平均绝对 logit；
- 扩展区绝对 logit 的 25% 分位数。

固定 V193 为回退策略，在 `SNR<-16.5 dB` 时尝试用高置信样本从 1 扩到 132，在 `[-16.5,-14.5)` 时尝试从 132 扩到 1152。阈值来自 seed1176/1177/1178 合并分位点，按 mean delta 和最差 seed 同时排序。

## 2. 结果

最稳健候选为：

```text
low confidence threshold = +inf
middle confidence threshold = 0.3013751507
```

它实际上禁止低段扩展，只在 seed1176 的中段命中极少样本：

| seed | 相对 V193 |
| ---: | ---: |
| 1176 | +0.000744 |
| 1177 | 0 |
| 1178 | 0 |
| 平均 | **+0.000248** |

更积极的门槛通常在 seed1177/1178 为正，却令 seed1176 回退 `0.018～0.021`。当前 `|logit|` 没有足够稳定的跨 seed 校准能力，近零候选不值得增加推理分支，因此 V194 拒绝。

## 3. 联合固定前缀复扫

同一批反事实数据还对三个 seed 联合重搜全部两阈值、八种中间前缀。V193 原策略：

```text
SNR < -16.5       -> 1 bit
-16.5 <= SNR < -14.5 -> 132 bit
SNR >= -14.5      -> 1152 bit
```

在 mean 和最差 seed 两种排序下均为第一，未发现更稳健的固定前缀替代项。这进一步支持保留 V193。

## 4. 结论

拒绝用未校准平均绝对 logit做输出扩展。若再次尝试置信度，必须训练独立校准头或直接监督“新增前缀是否产生正分”，不能继续扫描同一手工统计量。
