# V265：复盘后的低 SNR Tx 局部解除共享消融

## 为什么改这一个因素

目标仍是超过69，但尚未达成。线上唯一用户确认的成绩是V223的67.01164987745；当前主干V257固定本地选型68.650598，两者不是同一模型，不能相减推算线上泛化差距。

近期完成实验（同固定选型口径，均非线上分数）：

| 版本 | 核心尝试 | 本地均分 | 结论 |
|---|---|---:|---|
| V250 | 独立8专家、RMS目标、72k | 68.606029 | 共享实验的对照 |
| V257 | 同父组共享输入及前8块 | 68.650598 | 已通过当前队列确认，保留主干 |
| V258 | 独立专家下解冻Encoder | 68.655811 | 确认未可靠超过V257 |
| V259 | batch400、固定720万抽样 | 68.552592 | 负向；更新次数也不同 |
| V260 | Rx按自身SNR路由 | 68.507019 | 负向 |
| V261 | 硬前向评分、直通秩梯度 | 68.635577 | 未超过主干 |
| V262 | 共享+解冻Encoder组合 | 68.640587 | 未见相对主干的组合收益 |
| V263 | RMS秩带宽0.025→0.05 | 68.654513 | 相对主干+0.003915，区间跨零，不晋级 |

这些版本并非全部与V257构成单因素比较，详见各版本协议。V263已完整72k且独立复核完成，不再等待或重复训练。

V264四项诊断已经完成：尾部91.01%来自自身SNR<-10；低专家整体提高会掩盖弱用户下降；匹配训练/验证差距仅约0.05—0.07，不支持严重过拟合作为主要解释；低父组Tx弱/强用户参数梯度在V257四批中三批冲突，独立V250一批冲突。不同训练检查点和参数空间不能证明共享导致冲突。这只支持局部解除共享的可检验假设，不保证提分。

## 唯一改动与不变项

以V257为对照，仅解除Tx专家0/1的输入层和前8个残差块共享。这两个专家对应pair-min SNR的[-20,-15)、[-15,-10)；不是按单个用户自身SNR路由。Tx专家2—7仍共享原高父组前缀，Rx全部保持原共享关系，各专家最后2块/输出头不变。

保持8个5dB专家、宽512深10、B=1152、NUM_BITS_PER_RE=8、冻结Encoder、全1152位输出、原RMS目标（温度0.5、Gaussian秩带宽0.025、公平权重0.3、原始BCE权重0.05）、batch100、Adam学习率1e-5、seed15240、原独立均匀SNR采样及全部其他训练协议。

重新从原V227父模型映射[0,0,1,1,1,1,1,1]初始化，使用全新Adam，完整72000步/720万信道抽样；不从V257训练后权重或资源探针续训。参数数目由共享解除自然增加，不额外补偿宽度或训练预算，否则引入第二因素。

CPU实际证明已通过：总参数84570760、可训练83767368、598个唯一可训练张量；8路单样本及批量初始化logits/损失完全一致，随机流一致，实际梯度与独立对照按共享组累加一致（最大误差9.32e-10）；两步Adam全部参数有有限梯度及状态，序列化恢复保持别名和输出。该证明不是正式训练或性能证据。
