# V263：共享专家主干的P10秩带宽单因素消融

## 假设与边界

V261、V262完整72k实验显示：效率小幅上升未必带来总分提升，P10波动可抵消均值收益。V256降温失败、V259增大batch失败，不能把降低代理误差或增加样本数直接等同于提分。本实验只检验较宽的P10秩核，是否改善当前V257条件下的训练结果。现有检索未发现同一V257、72k、RMS条件下的纯带宽消融；旧V224同时改公平权重和带宽，不是该对照。

每批100信道、200UE，Gaussian秩核标准差由5名扩大到10名（带宽0.025→0.05），中心仍是0.1×199=19.9名。它增加周边UE梯度覆盖，也可能偏离真正P10；不声称无偏、必然稳定或保证单调收敛。不改变评分定义、公平权重、温度、BCE或模型。

## 预登记协议

唯一对照为已发布V257的完整72k结果。仍共享前8层、私有后2层及头，八段whole-min SNR 5dB专家、冻结Encoder，72744448可训练参数。使用原V227父权重映射[0,0,1,1,1,1,1,1]重新初始化，不从V257最佳权重或探针续训。fresh Adam1e-5、batch100、seed15240、72000步、patience72、每1000步固定2000验证信道；RMS温度0.5、原始BCE0.05、公平0.3、分位0.1、FP32和GPU上限0.4保持不变。

先使用原训练入口运行batch100两步探针，检查有限输出、完整初始化及架构一致；随后独立完整72k。现有V257架构及完整Adam GPU证明可复用，因为带宽不改变张量形状、参数及优化器状态。保留所有原始报告，不提前截断或审计部分训练。

固定本地选型split1176/test offset2000、2000信道/4000UE、noise22701/22702/22703、全1152位，始终以0.7效率+0.3硬P10选择及报告。配对bootstrap2000次seed227，信道为单位且两个UE与三噪声共同重采样。仅三组总分均正提升且95%区间下界>0才有资格另行登记确认；不得直接晋级main。

现有测试窗口历史复用及祖先训练谱系缺口仍然存在，不称全项目盲测。若候选达晋级门槛，必须在运行确认前检查尚未参与选型的确认来源及重叠；无法证明时明确报告限制，不把复用窗口改名为盲集。所有成绩均为本地结果，线上只认用户实际提交反馈。
