# V157 第一扩展组置信度守卫（外部验证淘汰）

日期：2026-08-25  
分支：`codex/extension-first-group-guard-v157`  
对照：V156

## 方法

在整体置信度门控已经决定返回 1056 bit 后，把 132-bit 扩展按 11 bit 分组；若第一组的截断平均绝对 LLR 小于 `0.043`，则改为只返回 924 bit。固定配对诊断中只触发 seed1176 的 2 个 UE 和 seed1177 的 1 个 UE，三者均为正增益。

## 外部验证否决

seed2100/2101 与 V156 严格同分；seed2102 出现唯一触发：

- SNR：`-7.583 dB`
- 输出长度：1056 → 924 bit
- 单 UE 得分变化：`-0.954857`
- final 变化：`-0.000167`

第一组低 LLR 并不能可靠预测整个 132-bit 扩展的平均正确率低于 50%。seed2102 违反逐 seed 非退化门禁，立即停止 2103–2108，V157 不合并主干。

## 结论

仅使用第一个 11-bit 组的置信度方差过大；若继续部分前缀方向，需要使用多个组的联合证据或直接学习单调停止规则，并在扩充 seed 配对诊断上训练，不能对 V157 阈值做局部追调。
