# V222：5-bit 配对 SNR 控制信令

## 假设与设计

V220 发射机知道两名 UE 的 SNR，但 Receiver 只看到自己的 SNR。用 5-bit 无损控制字段把两用户最大 SNR 量化为 32 档（约 1.25 dB/档），并用零初始化控制嵌入条件化 Receiver。控制字段只承载传输状态，不承载数据 bit。

## 消融结果

冻结 Encoder 与 Transmitter，只训练 Receiver 8k steps。相同固定验证集从 65.886364 增至 65.906850（+0.020486），P10 未跳档。

官方兼容严格 seed1176/2000：Efficiency 71.402734、P10 53.038194、Final 65.893372。相比 V220 的 65.896233 低 0.002860，因此否决。

## 结论

另一用户 SNR 对当前共享 Receiver 的边际价值很小；控制信令更适合用于真正改变数据率或传输模式，而不是只作为连续 Receiver 的附加特征。
