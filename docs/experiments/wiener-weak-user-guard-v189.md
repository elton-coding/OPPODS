## 假设与实现

V175 证明发送端 Wiener scale `0.875` 有明显均值收益，但任一 UE 命中 `[2.75,11.25) dB` 就改变整个配对波形，会让另一名弱用户跨过 P10 排序边界。V189 保留原参数和区间，只新增一个物理保护条件：

`any UE in [2.75,11.25) AND min(pair SNR) >= 3.75 dB`

满足时两个 UE 共用的 Wiener noise scale 从 `0.75` 变为 `0.875`；否则完全保持 V156。模型权重、反馈比特、RZF、Receiver 和输出长度策略均不变。
