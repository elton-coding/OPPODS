# V124 置信度门限小区间复扫

日期：2026-08-24  
分支：`feature/confidence-bins-v124`  
对照：V124，全中档区间门限 0.3

新增默认为空的 `MIDDLE_EXTENSION_CONFIDENCE_THRESHOLD_INTERVALS`，支持
按 UE SNR 覆盖置信度门限；默认结果与 V124 精确一致。

seed1176、1000 样本测试：

- `[-5,-2.5)` 提高到 0.35/0.40：均为 `62.920169`；
- `[-5,-2.5)` 提高到 0.50：`62.920443`；
- V124 全局 0.3：`62.921597`；
- `[-7.5,-5)` 降到 0.25：与 V124 完全相同；
- 低端 0.25 + 高端 0.35：同高端 0.35，退化。

提高高端门限会剔除净正收益扩展，降低低端门限在该样本集没有改变决策。
没有候选进入其他 seed，保持 V124 全局 0.3。区间接口保留在特性分支。
