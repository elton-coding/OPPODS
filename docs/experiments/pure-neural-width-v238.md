# V238：保函数扩宽512→1024（预登记，准备阶段）

## 动机

近期条件信息小分支未检出可靠收益。本实验准备检验逐RE纯神经收发主干是否受宽度限制，与V237学习率实验分开，不混合改动。去年队伍也曾报告扩容无效，因此扩宽只是假设，不能预设必然涨分。

## 唯一容量变化与初始化

沿用V227的两组联合最低SNR专家、共享冻结Encoder、k8/B1152及10个残差MLP块。Tx/Rx主干宽度512→1024；比特嵌入32、反馈展开16、Encoder、输入输出和控制语义均不变。不增加物理模块、已知信道算法或额外信息。

不是随机丢弃父模型：主干隐藏通道复制两份，线性层重复输入列并除以2，重复输出行，LayerNorm参数对应复制。重复的输入列加入1%原权重RMS的正负配对扰动；在输入副本相同时两列扰动抵消，保持初始函数，同时使反向梯度能够打破副本对称。严格检查父模型全部键名及尺寸，不允许漏加载。允许浮点舍入误差，须检查真实父权重的起始验证分。

训练时对残差块做激活重算以降低显存，仍FP32、batch100；推理无此额外操作。测试必须确认重算与普通前向及梯度一致，不更改当前在训代码或其数值路径。

## 正式训练计划与门禁

共同父模型artifacts/pure_neural_v227/joint_low，映射[0,1]。拟使用与V230C一致的Adam1e-5、seed15240、12000步、validation2000每1000步、patience12、全SNR均匀采样；soft_score T0.5/P10权重0.3/tail_fraction0.1/带宽0.025/BCE0.05。只有容量与其保函数初始化发生变化，不采用V237高学习率。

先完成CPU函数/梯度测试；再在空闲训练槽做隔离资源探针，确认batch100能在显存预算内训练，才能建立新的正式输出完整训练。小探针不得充当效果结果。与V230C做方法对照，与届时主干冠军做晋级对照；参数、包大小和实际推理耗时均须复核。固定audit后仍须保护未参与选型的确认窗口。

CPU测试已通过：两种核心的初始函数在浮点容差内一致，复制通道获得不同梯度，缺失父权重会拒绝加载；激活重算与普通路径的输出和梯度逐元素相同。模型参数实际计数为174338872（Encoder803392、Tx89383124、Rx84152356），不以此推断压缩包大小或速度。

另外使用真实V227全部权重，在CPU上对3个覆盖低/高路由的合成信道及相同链路噪声验证：6912个logit的最大绝对差6.3211e-5、平均差9.4538e-7，硬判决差异0。证据benchmarks/v238_parent_parity_cpu.json含父权重与设计哈希。这不是validation或效果分数，GPU真实验证起点仍须正式确认。
