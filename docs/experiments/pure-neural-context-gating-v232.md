# V232：通用神经条件门控（预登记）

假设：原Receiver首先把信道、接收信号和SNR线性相加，再交给MLP。增加一个小型通用神经条件分支，学习特征的乘性缩放和偏移，可能更容易适应不同信道，而不是单纯加深网络。

实现：H实虚特征及SNR→65维→128维GELU→1024维，输出512维scale和shift；作用于原Receiver输入嵌入 `v*(1+scale)+shift`。最后投影层全零初始化，保证训练起点与V227完全一致。没有添加显式均衡、预编码、匹配滤波或其他物理计算；仍是纯神经网络。

单因素对照复用V230两专家续训。相同V227父模型、两专家[0,1]、冻结Encoder、全部Tx/Rx训练；seed15240、batch100、Adam1e-5、12000步、每1000步验证2000通道；软评分T0.5及其余参数不变。输出 `artifacts/pure_neural_v232/context`。本次不同时改变专家数量和温度。

只有新增_context参数允许从零初始化，其余所有参数必须完整加载；检查初始输出一致。固定validation选点，audit配对确认，若达到69再用未参与选型的新窗口复核。不将训练内峰值直接当作最终成绩。
