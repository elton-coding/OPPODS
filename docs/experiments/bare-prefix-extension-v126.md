# V126 裸 924 位回退的高 SNR 扩展

日期：2026-08-24  
分支：`feature/adaptive-extension-length-v126`  
对照：V125

## 动机与诊断

V125 的中等 SNR 分支有三种结果：置信度通过时输出物理 LLR 1056 位；阈值控制命中时输出 924 位物理 LLR 加 Walsh 尾部至 1152 位；其余情况只输出裸 924 位。

诊断工具增加 12 个 11-bit QAM 组的置信度和 `924/935/…/1056` 共 13 个候选前缀分数。逐组置信度门控没有泛化，但按回退语义分层后发现：仅对裸 924 位用户，在 `[-7.5,-2.5) dB` 直接使用 1056 位物理 LLR，三个种子均提升；低于 `-7.5 dB` 则存在明显公平性风险。

## 最终规则

保持 V125 的置信度扩展和 Walsh 1152 位尾部优先级不变。只有原逻辑最终要返回裸 924 位、且 UE SNR 不低于 `-7.5 dB` 时，才返回物理 LLR 的前 1056 位。
