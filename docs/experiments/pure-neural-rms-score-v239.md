# V239：评分代理的逐UE尺度不变性（已完成，待组合验证）

## 可证伪假设

官方硬判决只看logit正负，正比例放大每个UE的所有logit不改变任何比特或官方得分；现soft_score代理却随放大改变。V231固定降低温度失败，并观察到模型输出标度改变。因此本次不再更换温度，而是检验：消除评分代理对每个UE整体输出标度的依赖，能否让优化更集中于改变错误判决。

这不是对V231失败原因的因果定论，也不能保证新代理提高硬评分。逐UE归一化可能改变不同SNR之间的软分数排序，这是本实验必须接受复评的风险。

## 唯一损失因素

令r=sqrt(max(mean(logit²),1e-8))，均值只在同一UE的1152bit内取；评分代理使用logit/r，完整保留r的梯度，不detach，不改变正负阈值。温度仍0.5、P10权重0.3、分位0.1、秩带宽0.025。

`L = -(0.7 * mean(sigmoid(signed_logit/r/T)) + 0.3 * soft_P10) + 0.05 * BCE(raw_logit, bit)`

只有评分代理归一化，BCE仍作用于原始logit，并非将BCE也换成归一化版本。正常非零范围内代理对每UE任意正尺度不变，其沿整体缩放方向的梯度为零；极近零处用RMS下限1e-4稳定数值。先clamp平方均值再sqrt，避免全零输入的sqrt导数产生NaN。
