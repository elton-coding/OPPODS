# V236：低SNR用户k4/B576，其余k8/B1152（已完成，拒绝）

## 目标与唯一因素

当前宽MLP的已记录载荷比较主要是k7与k8。尚未在同一宽网络、评分代理及完整重训下检验“低SNR少传、配对强用户仍多传”。本实验只改变**每个用户自己的载荷策略**：自身SNR<-15dB时每RE4bit，共576bit；其余仍每RE8bit，共1152bit。阈值预先固定，不在audit上调参。

不是把已有k8输出直接截断到576bit。Tx把源序列前576bit铺到全部144个RE，每个RE前4个输入槽承载数据，后4个槽固定为0.5（输入均值）。Rx从每RE取对应4个输出，再按源序列顺序打包。强用户仍发送/输出1152bit，即便与低SNR用户共享同一个Tx/Rx专家。

## 模型与训练控制

- 仍为两组联合最低SNR专家，边界-10dB；共享Encoder冻结，所有Tx/Rx训练。
- 纯神经网络，无新的物理预编码/均衡；5bit控制、96复上行符号、48191288参数均不变。
- 从与V230C相同的V227父模型严格映射[0,1]继承全部权重，不是随机从零训练；随后完整重新训练。高SNR起点输出与父模型逐元素一致；低SNR因载荷映射改变，初始评分允许不同并必须记录。
- seed15240、batch100、Adam1e-5、12000步、每1000步validation2000，patience12，FP32，显存上限0.4。
- soft_score T0.5、P10权重0.3、分位0.1、秩带宽0.025、BCE0.05不变。
- design=research/pure_neural_v236/modelDesign.py，output=artifacts/pure_neural_v236/low_k4；同预算对照=V230C。

## 未传比特的评分与实现门禁

训练的混合batch用零填充将输出整理成1152位，但这只是张量形状处理，**不能将填充当作实际猜测**。soft/hard代理和验证均显式按实际载荷长度掩码，未传部分严格计50%且无梯度。正式逐样本Receiver只返回576或1152个真实输出；官方兼容evaluator按原规则补50%。

关键测试包括：使用全部144个RE而非仅前72个；改变未传源bit不会改变低用户输入；收发打包顺序相符；低/强用户可不同长度；单样本链路可正确整理不同用户长度；缺失576bit且已传全对时恰为75分；改变填充logit不改变分数或目标且无梯度；原固定长度评分逐元素不变。

日志中的验证BCE对零填充项含常数log(2)，不是正式总分，不据它选冠军。小型logit尺度诊断暂拒绝可变载荷模型，避免错误地把填充判成1；正式评测和训练validation已经支持精确中性计分。
