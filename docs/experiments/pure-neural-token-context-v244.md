## 依据与历史区别

当前V227/V240主干的收发残差块逐子载波执行。Tx反馈展开虽然可携带全频CSI，但某个子载波的bit特征没有通过主干与其他子载波的bit特征交换；Rx主干只处理本子载波y/H。检验在现有纯神经链路上加入可训练跨子载波上下文是否有净收益，不引入物理求解或额外侧信息。

历史V215整体替换Receiver为随机初始化Mixer，且同时经历BCE/Hinge训练，未超过当时V213。它不能作为此次收益依据。本次新假设是保留已有收发解、零初始化小残差并联合适配Tx/Rx，和“整体随机换接收机”不同；若失败，不将其纳入默认组合池。也不因模块名称相同声称此前从未尝试跨频结构。

## 唯一特性及对照

从原V227两专家初始化，Encoder冻结，训练全部Tx/Rx；k8/B1152、96复反馈、5bit控制、SNR边界[-20,-10,20]、宽512/10块均保持。Tx与Rx各专家在第5个残差块后加入一个TokenContext：LayerNorm→512到64降维→GELU→沿144个子载波的可学习144×144线性混合→GELU→64到512升维，乘0.1再与输入相加。升维权重与偏置全零，因此初始输出精确保持父模型，升维层在第一步获得梯度；其余新层随后获得梯度。总新增351488参数，总参数48542776。

这项因子包含小量参数增加和跨子载波连接两者；不把一次提高单独归因于信息交换而忽略容量差异。若可靠有效，后续再用相同参数量、禁止跨子载波的模块隔离作用机制。

直接方法对照V230C：同V227、seed15240、batch100、Adam1e-5、12000步、验证2000每1000步、patience12、soft_score T0.5/P10权重0.3/BCE0.05/带宽0.025、全SNR独立均匀，不叠加RMS、扩宽、学习率或36k预算改动。所有正式权重从父模型重新初始化，不从两步探针续训。V240C及届时最新冠军仅用作额外发布比较，不能将不同预算比较解释为纯模块增益。
