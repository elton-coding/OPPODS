# V204 V199 输出前缀联合复扫（未采用）

## 方法

V193 的输出前缀阈值是在 V192 权重上选择的。V204 保持 V199 权重不变，分别在 seed 1176/1177/1178、每个 2000 信道样本上生成完整 logits 的多前缀反事实分数，然后联合搜索低阈值、中间前缀长度和高阈值。

## 结果

V199 当前策略为低阈值 `-16.5 dB`、中间前缀 132 bit、高阈值 `-14.5 dB`，三种子均分 `62.429390`。

最高均值候选为 `-13.5 dB / 792 bit / -13.0 dB`：

- 三种子均分 `62.429743`，平均仅增加 `0.000353`；
- seed 1176 下降 `0.011936`；
- seed 1177 下降 `0.000375`；
- seed 1178 上升 `0.013370`。

按最差种子增量排序，当前 V199 策略仍为第一，其他候选都至少有一个种子退化。

## 结论

新权重没有改变稳健最优前缀策略。最高均值候选依靠种子间抵消，风险明显，不采用。V199 的 `1/132/1152` 策略和两个阈值继续冻结。下一版扫描已训练专家 1/2 附近的 SNR 路由边界。
