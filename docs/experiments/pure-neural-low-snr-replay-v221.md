# V221：低 SNR 聚焦回放

## 假设

V220 严格评分的最差 10% 样本中，SNR 中位数为 -16.15 dB，90% 低于 -9.66 dB。因此尝试增加低 SNR 训练密度，同时保留全区间回放。

## 消融

- 起点：V220 long-tail 最佳权重。
- 75% 的单 UE SNR 从 `[-20,-8]` dB 采样，25% 从完整 `[-20,20]` dB 采样。
- Hinge+BCE，lr `1e-5`，固定均匀全区间验证。

同一验证集 step 0 为 65.967848；750/1500/2250/3000 steps 分别为 65.773388、65.778115、65.774254、65.748661。连续四次未超过起点后早停并恢复起始权重。

## 结论

低 SNR 分布重加权同时损害效率和 P10，否决。剩余瓶颈不是简单的低 SNR 样本数量不足，而更可能是弱用户接收机缺少另一用户状态、或网络的信息交互能力不足。
