# V127 控制阈值余量扩展（拒绝）

日期：2026-08-24  
分支：`feature/control-margin-extension-v127`  
对照：V126

## 方法

诊断中增加控制索引、解码控制阈值和 `SNR - control_threshold` 余量。对于 `[-10,-7.5) dB` 中原本返回裸 924 位的用户，尝试仅在控制余量足够大时扩展到 1056 位。

margin=5 dB 在 seed1176–1178 的前 1000 样本及前后半区均非负，因此进入完整复验。

## 完整结果

针对失败种子单独复验更保守的 margin=6 dB，final 为 `62.858155`，相对 V126 进一步下降 `-0.000289`。

## 决策

margin=5 未满足六种子全正硬门槛，margin=6 更差。模型改动拒绝并移除；控制余量诊断字段保留，供后续分析控制语义使用。
