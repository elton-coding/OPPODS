# V123 Walsh 截断几何搜索

日期：2026-08-24  
分支：`feature/walsh-geometry-v123`  
对照：V123 start65–80

## 方法

对 Walsh 1–255 行取前 228 列，以二进制模板映射到 `{-1,+1}`，计算
所有行的截断内积。对每个起始行执行 16 行贪心选择，按最大绝对互相关、
互相关平方和、绝对和依次最小化。该目标不使用验证 bits 或 score。

通用工具为 `scripts/search_walsh_rows.py`；实验分支同时支持显式
`THRESHOLD_WALSH_ROWS`，默认空列表与 V123 精确一致。

## 结果

V123 start65–80 的几何指标：

- 最大绝对互相关：`4`；
- RMS 绝对互相关：`1.7888543819998317`；
- 平均绝对互相关：`0.8`。

遍历 255 个贪心起点后，最优候选只能达到完全相同的三项指标，没有任何
集合严格优于 V123。许多连续 16 行块都达到该下界，验证分数差异主要来自
模板/门限/随机 bits 的具体映射，而不是更低的几何相关性。

## 决策

V123 已处于本搜索空间的几何最优边界。不再用固定验证集在同指标集合间
挑选，避免过拟合；显式行接口与搜索工具保留在特性分支，不合入主干。
