# V198 冻结 Receiver 的非对称微调

## 方案

V198 是 V196 组件消融后的定向修正，保持以下内容不变：

- 8 个固定 5 dB SNR 专家；
- 组件级路由：每名用户的 Encoder、反馈 Decoder、神经调制器和 Receiver 按自身 SNR，共享 Precoder 按双用户较低 SNR；
- V193 的 `1/132/1152` 输出前缀策略；
- 全链路纯神经黑盒，不使用显式信道估计、均衡、干扰抵消或解析预编码。

训练时每个样本的一名用户落在专家 1 的 `[-15,-10) dB`，另一名用户覆盖完整 `[-20,20] dB`，并交替目标用户。目标用户损失权重为 `1.0`，上下文用户为 `0.25`。只更新专家 1 的 Encoder 和 Transmitter，Receiver 从第 0 step 起冻结。

超参数：400 step、batch size 32、学习率 `1e-5`、tail weight `0.5`、tail fraction `0.1`、1024 个验证信道；验证最优点为 step 200。

三个固定种子全部提升，增益来自 efficiency，P10 保持不变。

## 结论

V198 替代 V193 成为纯神经主线最佳候选。它验证了 V196 的诊断：非对称训练的主要退化来自 Receiver 更新，冻结 Receiver 后可获得跨种子一致的小幅收益。

V198 的三种子均分仍低于总榜主干 V190 的 `63.217950`，差距约 `0.790556`，因此本分支不合并 `main`。后续纯神经实验应继续采用“Receiver 冻结、逐专家独立验证”的方式，并优先尝试专家 2 或 4，不同时改动多个专家。
