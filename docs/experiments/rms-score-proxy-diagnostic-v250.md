# V250：RMS评分代理与硬P10的对齐诊断

2026-09-10预先限定诊断范围。此分支不创建新训练版本、不改变任何在训或排队实验，仅用CPU读取冻结V250权重，分析损失代理的排序与梯度位置。

数据固定split1176的前400个训练信道，不挑样本、不用确认集；按4批×100信道，使用独立诊断随机种子27150生成全1152位bits、均匀[-20,20]两UE SNR及噪声。这些信道属于训练划分，结果不能称泛化评测或竞赛新分数。保存的缓存只含logits/bits/SNR/训练索引，不复制原始H，也不写模型权重。

分析温度仅原主线0.5和已试过的0.25两个固定值，二者作用于同一批冻结V250输出；这不等同于重训后的V256，不用于搜索新温度。统计每个真实200UE批次及汇总800UE：硬判决与RMS soft-score的平均秩相关、底部10%重合率、Gaussian rank权重落在硬P10上下1分内的比例，以及实际总损失/单独P10代理对logits的绝对梯度质量分布。所有量都作为描述，不从相关或梯度位置直接推断训练能提分。

实现须复用原RMS函数并检查解析重建的总损失与原函数一致；量化规则使用>=0判为1、torch线性插值quantile及平均秩处理并列。Gaussian权重参数保持tail0.1/bandwidth0.025；BCE0.05与公平权重0.3不变。额外比较4个batch200UE与汇总800UE仅是当前样本分组的描述，不是V259大批次训练成绩、也不保证减小代理偏差。

CPU开销独立于两项GPU训练；数据/四模型文件/损失及诊断源码SHA在运行前后固定，输出与缓存排他生成，不覆盖旧证据。实施、检查和结论在实际完成后追加。
