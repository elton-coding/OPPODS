# V184 Receiver 数据向量 temperature 专家（拒绝）

日期：2026-08-25  
分支：`codex/receiver-data-vector-temperature-v184`  
对照：V156，默认 `DATA_VECTOR_SOFT_TEMPERATURE=3.0`

## 方法

保留 V118 已有 `[0,2.5)`、`[5,7.5)` 的 temperature `2.0` 专家，只把
其他区间的默认值扫描为 `1.5/2.5/3.5/4.0`，保存逐 UE exact score。

seed1176、500 样本中，`1.5/2.5` 的大幅表观收益主要来自低 SNR P10
正向跳档，按风险规则不优先扩样。`3.5` 另有不依赖 P10 的高 SNR候选
`[10.25,19.75) dB`：增益 `+0.001762`，两半块最差 `+0.001701`，因此
冻结 value 后生成六个发现 seed 的完整反事实。

## 结论

保留 V156 的默认 `3.0` 及两个既有 `2.0` 专家；不实现新 temperature
区间、不进入盲测、不生成提交包或修改主干。
