# V127 Walsh 尾部置信度再校准

日期：2026-08-24  
分支：`feature/walsh-tail-confidence-v127`  
对照：V126

## 方法

V126 已将 `[-7.5,-2.5) dB` 中原本返回裸 924 位的用户直接扩展到 1056 位。因此该区间的置信度门控只剩一种语义：在 1056 位物理 LLR 与 1152 位 Walsh 尾部之间选择。

仅对 `fallback_length=1152` 的诊断样本重新扫描截断均值门限。六种子非劣解将 `[-7.5,-5)` 与 `[-5,-2.5)` 的门限从 `0.246` 提高到 `0.260`，更保守地保留 Walsh 尾部。
