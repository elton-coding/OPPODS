# V217：共享发射链路的 16 个 Receiver 专家

V217 将 V216 权重复制为 16 个 2.5 dB Receiver 专家，Encoder/Transmitter 保持共享冻结，并在双用户独立随机 SNR 下训练。

初始化阶段发现并修复了单专家权重键 `experts.0.*` 未剥离的问题；修复后 500 样本烟雾测试为 65.091997，与 V216 一致。错误初始化产生的 51 分结果作废。

最低区间 `[-20,-17.5)` 的非对称 Receiver 微调，在 500 步内仅将局部混合验证从 60.277983 提升到 60.362703（+0.084719）。该幅度不足以解释距离 67 的差距，因此停止其余 Receiver-only 专家训练。

结论：仅接收端分箱不足。下一版改为由双用户最低 SNR 选择一致的联合 Transmitter+Receiver profile，并通过控制比特向 Receiver 传递 profile 编号。
