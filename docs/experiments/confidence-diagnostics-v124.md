# V124 中等 SNR 扩展置信度诊断

## 目的

定位 `[-20, -2.5) dB` 分支中从 924 位扩展到 1056 位的可靠门控，避免只调全局均值阈值造成 P10 回退。

## 方法

- `evaluate_submission.py --extension-diagnostics-out` 对每个中等 SNR UE 同时计算原 924 位回退输出和 1056 位输出。
- 保存扩展段绝对 LLR 的均值、中位数、四分位数、标准差和截断均值，以及两种输出的配对真实分数。
- `search_extension_policy.py` 将诊断样本映射回完整 4000 个 UE 分数，在三个固定种子上搜索全局门控和 2.5 dB SNR 分箱门控。
- 候选必须满足三个种子的最终分数增益均不为负。

## 数据一致性

三个种子的诊断评测均精确复现 V124 正式指标：

| seed | V124 final |
|---:|---:|
| 1176 | 62.998805 |
| 1177 | 63.237718 |
| 1178 | 63.182900 |

诊断回退分数与 V123 归档的最大差异为 `3.4e-6`，来自归档的 float32 精度。`mean_abs >= 0.3` 逐项重建 V124 的选择结果。

## 搜索结论

- 最佳简单全局门控：扩展段 `mean(abs(LLR).clamp(max=1.0)) >= 0.2462184`。
- 最佳 2.5 dB 分箱候选沿用该统计量，并在每个 SNR 小区间使用独立阈值。
- 分箱候选相对 V123 的三种子平均 final 增益为 `+0.002517`，最差种子增益为 `+0.001276`；V124 对应为 `+0.001712/+0.001155`。
- 该候选在三个种子的前后半区共六个切片中均保持正增益，P10 均未变化。

搜索结果保存在本地忽略目录 `artifacts/diagnostics/extension_policy_search_v124.json`。候选仍需由真实接收机实现并使用未参与搜索的新种子验证后，才可晋升。
