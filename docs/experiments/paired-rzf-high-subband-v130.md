# V130 极高 SNR RZF 子专家实验

日期：2026-08-24  
分支：`codex/paired-rzf-high-subband-v130`  
对照：V129

## 方法

在 V129 的双 UE 高 SNR `0.90` RZF 专家内部继续分段。当两个 UE 都至少为 `4.0 dB` 时，将正则提高到 `1.20`；`[-0.75,4.0)` 仍使用 `0.90`。中低 SNR 的 `0.40/0.45` 路由不变。

使用全局 `1.20` 反事实扫描双 UE 矩形区间后，`[4,20) dB` 不是固定均值最高的门限，但在 seed1176/1177/1178 上具有更均衡的最差 seed 增益，因此按稳健性冻结。
