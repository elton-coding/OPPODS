# V196 目标加权上下文与组件消融（未采用）

## 改动

V196 延续 V195 的非对称 SNR 采样，但把目标用户与上下文用户的损失分开。目标用户梯度权重为 `1.0`，上下文用户为 `0.25`，同时把验证样本从 512 增加到 1024。实验选择 V195 中最接近持平的专家 1（`[-15,-10) dB`），从 V192 权重重新训练 400 step。

训练后进一步增加组件级模型组合工具，可仅替换指定专家的 Encoder、Transmitter 或 Receiver，以定位收益和退化来源。

## seed 1176 组件消融

V193 固定基准为 `62.421438`。

| V196 专家 1 更新范围 | 固定分 | 相对 V193 |
|---|---:|---:|
| Encoder + Transmitter + Receiver | `62.389973` | `-0.031465` |
| Receiver only | `62.391659` | `-0.029779` |
| Transmitter only | `62.420769` | `-0.000669` |
| Encoder only | `62.421514` | `+0.000076` |

接收器更新贡献了绝大部分退化；编码器单独更新在该种子上只有极小正差。

## 结论

目标加权没有解决泛化问题，候选不采用。组件消融表明后续非对称训练不应继续等学习率更新完整专家：Receiver 应冻结或使用显著更小的学习率；Encoder 更新虽然稳定，但当前收益低于评测噪声。主候选继续保持 V193，主干继续保持总分更高的 V190。
