# V213：k=7、B=1008 低学习率续训消融

## 目的

验证 V212 最优纯神经黑盒模型是否仍受训练步数不足限制。模型结构、`NUM_BITS_PER_RE=7` 与 `B=1008` 均保持不变，只把训练从 40k 延长，并把学习率降至 `3e-5`。

## 训练设置

- 初始化：V212 在固定验证集上的最佳权重；优化器状态与全局步数从 40k 检查点恢复。
- batch size：100。
- 验证：每 5k 步、2000 个样本。
- 止损规则：若 60k 前未出现足以支持继续长训的增益，则停止。
- 评分：官方兼容的逐样本、双用户评分，最终分为 `0.7 * efficiency + 0.3 * P10`。

训练器新增 `--resume-best`，允许保留最后检查点的优化器与步数，同时从已保存的最佳组件权重继续；恢复后显式采用命令行指定的新学习率。

最佳权重出现在 50k 前后；55k 与 60k 的平均准确率仍略升，但 P10 回落，最终分随之下降。因此按预设规则在 60k 停止。

## 三 seed 严格复评

每个 seed 使用 2000 个信道样本、4000 个用户分数，接收端固定输出 1008 位；未发送的 144 位按赛事规则折算为 50% 正确率。

## 结论

低学习率续训产生了跨 seed 一致的正增益，但 50k 后已经进入平台期，继续投入同类训练无法解释约 4.38 分的目标差距。V213 保留为纯神经单模型的新对照组，不晋升总主干 V190。下一版本转向分 SNR 专家和面向 P10 的训练，不再单纯增加全区间统一模型的训练步数。
