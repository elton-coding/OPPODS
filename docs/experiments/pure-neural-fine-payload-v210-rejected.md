# V210 V208 细粒度动态 B 联合搜索

## 方法

固定 V208 权重与 `NUM_BITS_PER_RE=8`，将动态输出 B 的候选扩展为：

`1/32/64/96/128/132/160/192/224/256/264/396/528/660/792/924/1008/1056/1152`

在 seed 1176/1177/1178 各 2000 信道样本上保存同 logits 的所有前缀反事实分数，联合搜索低 SNR 阈值、中档 B、高 SNR 阈值和高档 B。高档 B 额外比较 `924/1008/1056/1152`。

## 结果

V208 基准策略为 `-16.5 dB / B=132 / -14.5 dB / B_high=1152`，三种子均分 `62.433709`。

最高均值候选为 `-17.0 dB / B=32 / -13.5 dB / B_high=1152`：

| seed | 相对 V208 |
|---:|---:|
| 1176 | `-0.006467` |
| 1177 | `+0.004865` |
| 1178 | `+0.023152` |
| mean | `+0.007184` |

该候选依赖种子间抵消，不能通过最差种子门禁。

靠近现有策略的 `B=128` 在 1176/1177 微升，但 1178 下降，均值为 `-0.000015`。按最差种子排序，V208 原策略仍为第一。

允许改变高档 B 后，所有排名靠前候选仍使用 1152；`924/1008/1056` 没有产生更优稳健策略。

## 结论

动态 B 已覆盖低、中、高载荷细粒度候选。当前稳健最优仍是 `1/132/1152`，不采用 V210 的任何新策略。结合 V209，最终保留 `NUM_BITS_PER_RE=8` 与 V208 的 B 策略。
