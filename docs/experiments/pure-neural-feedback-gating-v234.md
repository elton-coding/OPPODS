# V234：发射端反馈—比特神经门控（已完成，未晋级）

状态：已完成12000步及三噪声配对audit，不晋级。最佳检查点10000步，validation总分68.187393；1957.7秒并行训练耗时不用于架构速度结论。

来源：去年“下午一点半”队伍采用反馈与比特表征相乘；现V227首先线性拼接这些特征，由深层MLP学习交互。本实验检验显式的**通用神经乘性条件化**是否有助于学习。无传统调制、均衡、预编码或解析信道重构。

唯一变化：每个用户在Tx内用逐RE的16维神经反馈特征与归一化SNR，经过17→128→64的GELU MLP，输出32维scale和shift，作用于32维比特嵌入 `bits_embedding*(1+scale)+shift`，再与原反馈特征按原顺序拼接。两个用户的分支独立；最终投影全零初始化。其余参数必须完整继承V227，初始化输出与父模型逐元素一致。

对照仍为V230 two_control_clean；固定共享Encoder、两组Tx/Rx专家、k8/B1152、soft_score T0.5/BCE0.05/P10权重0.3。拟从V227映射[0,1]训练全部Tx/Rx，seed15240、batch100、Adam1e-5、12000步、每1000步验证2000通道；显存分配上限0.4。

不与V232的接收端门控混合，不改变控制字段；若单项均有效，再另建组合实验验证交互效应。输出路径预留为artifacts/pure_neural_v234/feedback。

该特性分支保留当前训练队列所需的研究源文件；可部署modelSubmit权重为已复核的V230E，候选未晋级。V227只是本轮各单因素实验的共同初始化父模型。
