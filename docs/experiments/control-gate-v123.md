# V123 control data-mode 门限复扫

日期：2026-08-24  
分支：`feature/control-gate-v123`  
对照：V123（10.25 dB）

V123 换用与阈值索引耦合的 Walsh 尾部码本后，重新参数化
`DATA_MODE_MIN_SNR_DB`。默认 10.25 dB 与 V123 精确一致。

seed1176、300 样本扫描 `6/8/9/10/11/12/13/15 dB`，只有 8 dB 超过
V123：`62.423358` 对 `62.420218`。8 dB 在 seed1177/1178 的 300 样本
也分别提升约 `+0.030425/+0.004709`，进入正式复验。

2000 样本 seed1176 上，8 dB 为 `62.994324`，低于 V123 的
`62.996329`，退化 `-0.002005`。由于已不满足所有 seed 全正，停止剩余
完整循环。

结论：保持 V123 的 10.25 dB。可配置门限接口保留在特性分支，不合入
`main`。
