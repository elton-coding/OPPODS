# 924-bit 中档前缀细粒度扫描

日期：2026-08-24  
分支：`feature/snr-middle-prefix-fine`  
对照：V120

将阈值尾部码本裁剪为恰好补足 1152 位后，默认 924 位输出与 V120 exact 完全一致。随后以 8-bit/QAM 符号对齐扫描 `884–1056` 位。

- 932 位以上均明显退化，更多不可靠主链 bit 无法替代控制模板；
- 884 位在 500×3 为正/负/正，seed 1177 回退约 `0.0264`；
- 916 位在 500×3 为负/正/负；
- 924 位保持当前冠军配置。

本轮没有候选通过多 seed 门槛，不合并 main。
