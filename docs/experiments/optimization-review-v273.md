# 截至V273的优化复盘与下一步决策

日期：2026-09-12。本文区分已完成证据、运行中实验和未验证假设，不把运行时长或版本数视为成果。

## 1. 当前结论

69分目标没有完成。主干是V269，main提交2d4170d，固定选型三噪声均分68.7785908565，距本地69还有0.2214091435。另一窗口条件性确认均分68.6421997975，相对V268提升0.0944688332，配对95%区间[0.0532157849,0.1462931455]。这是本地证据，不是线上成绩。

唯一用户反馈的线上成绩是V223的67.01164987745，不能将它与V269本地分数相减当作线上提升。确认窗口2000/2000信道已在历史评测出现；换噪声没有带来全项目未见信道，反复选型存在选择偏差。现有置信区间不是对全部历史试验进行多重比较校正后的保证。

## 2. 主干究竟用了什么

纯神经网络Encoder/Transmitter/Receiver链路，不增加解析物理求解模块。双用户最小SNR在[-20,20]按5dB划成八专家；不是八个完全独立网络：继承V227父模型映射[0,0,1,1,1,1,1,1]，同父组共享输入和前8个残差块，各专家保留末2块及输出头。宽度512、10块，Encoder冻结，可训练参数72,744,448。

B=1152、NUM_BITS_PER_RE=8。主干从V227初始化，以新Adam训练72000步、batch100、恒定学习率3e-5；验证选择68000步检查点。

损失已经不是只用官方原始BCE：逐用户logit进行可求导RMS归一化，使用温度0.5的平滑正确率及P10附近秩加权评分代理，公平权重0.3、秩带宽0.025，再加0.05倍原始logit BCE。评分代理对应平均效率与尾部目标，但不等价于硬判决的真实评分，也不保证每步分数单调增加。训练记录中的loss为验证BCE，不能把它当作完整训练目标。

## 4. 两天仍未达标的原因：证据与不足

1. 最近主要是局部超参数搜索。V270—V272耗费三个完整72k预算，都未通过可靠提升门槛。学习率附近细分与BCE减半这条路径应关闭，不继续试3.25e-5或类似小数值，也不把三个小均值差累加成预计收益。
2. 尾部不是简单的专家平均问题。V264对V257发现约91%的尾部用户自身SNR低于-10dB；同一pair-min专家还服务较强伙伴，专家整体平均上涨可能掩盖弱用户下降。此结论来自旧主干，不能未经核实直接当作V269的当前瓶颈。
3. 局部梯度诊断不等于最终因果。V264发现低SNR Tx弱/强条件存在冲突，但V265解除共享后反而下降。因此不能继续以“取消共享一定解决冲突”为依据投入训练。
4. 训练预算不足尚未证明。V269验证最佳68k接近72k终点，值得测更长训练；但这不是收敛不足的证明。旧训练/验证诊断也仅说明没有观察到巨大差距，不证明一定欠拟合。
5. 记录管理存在过期状态。消融总表顶部仍写V250，交接累积大量历史运行状态，妨碍快速判断。此次修正总表并新增集中复盘，不改冻结实验输入。

## 5. 当前执行与后续决策

已核实V273正式父进程42400、子进程66072存活，最近观察52000/144000步；没有第二条训练队列。保持当前冻结协议，不重启、不改损失、不提前从中途检查点评测选型。这轮从V227新初始化，前72k用于复现V269轨迹；总样本抽取14.4M，对比7.2M，明确不是等计算量对照。

完成后首先检查145个验证点与前73点复现、真实模型及固定配对评测。只有三个噪声综合分差都为正且配对区间下界为正，才进入冻结条件确认。否则保留V269，不以某个验证峰值或单噪声超过69宣布达标。

下一步不自动再翻倍训练，也不重复已否定的试参。先对完成后的V269/V273做一次归因复盘：后72k的验证硬评分是否稳定改善、效率/P10分别如何、收益是否集中于原有尾部；测试切片只作描述，不用于挑格子拼接。

若144k无可靠收益，优先在训练/验证划分诊断当前主干的“评分代理改善是否伴随硬P10改善”。有失配证据后才设计一个评分代理校准因素；若没有失配证据，不预先指定新损失或宣称其可达69。任何新训练必须写清待证伪机制、对照、预算、停止探索条件；不把机制诊断扩展为又一轮无限搜索。

只有本地可靠提升、异常或完成时汇报。线上69仍需真实平台反馈验证，不作达标时间或必胜承诺。
