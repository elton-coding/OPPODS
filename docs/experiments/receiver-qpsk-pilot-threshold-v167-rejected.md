# V167 QPSK 导频相位位起始阈值（拒绝）

日期：2026-08-25  
分支：`codex/receiver-qpsk-pilot-threshold-v167`  
对照：V156

## 方法

V156 在单 UE `SNR>=2.5 dB` 时附加 2 个 QPSK 导频相位位。本轮初筛阈值 `2.0/2.25/2.75/3.0 dB`，并分别对两个独立方向执行 6-seed discovery：

- `2.75`：删除 `[2.5,2.75)` 的相位位；
- `2.25`：新增 `[2.25,2.5)` 的相位位。

使用 seed1176/1177/1178/2120/2121/2122，各 2000 样本；阈值在初筛后冻结，不再搜索边界。

## 六 discovery seed 结果

| Seed | 阈值 2.75 增益 | 阈值 2.25 增益 |
|---:|---:|---:|
| 1176 | -0.001337 | -0.000167 |
| 1177 | +0.002172 | -0.000273 |
| 1178 | -0.000501 | -0.001868 |
| 2120 | +0.000927 | -0.001686 |
| 2121 | -0.000365 | +0.023589 |
| 2122 | +0.000668 | -0.000076 |

`2.75` 为三正三负，方向不一致。`2.25` 有 5 个 seed 回退；seed2121 的大正值来自 P10 离散上跳 `+0.078123`，其效率仅提高 `+0.000217`，不能代表稳定链路收益。

结论：当前 `2.5 dB` 边界保持不变。V167 在 discovery 阶段拒绝，不进入真正盲测、不修改模型、不构建包、不合并 `main`；冠军继续为 V156。
