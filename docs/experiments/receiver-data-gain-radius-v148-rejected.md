# Receiver data-gain radius profiles V148（拒绝）

## 假设

在不同 SNR 小区间使用不同的数据增益细化搜索半径，可能比全域固定半径 2 更好。候选在 `4.25 <= SNR < 8.75 dB` 使用半径 3，其余区间保持 V147。

## 实现

- 特性分支：`codex/receiver-data-gain-radius-profiles-v148`
- 源码提交：`683a019`
- 使用半开区间路由；区间内外分别保持半径 3/2 的原始浮点求和顺序。
- 38 项测试通过，Ruff 通过。
- implemented 结果与逐 UE 反事实拼接完全一致（2000/2000 UE exact）。

平均增益约 `+0.000349`，但 seed1177 退化，未满足固定 seed 全正条件。

## 边界稳健性复核

把三个 fixed seed 各切为四段，共 12 个留出块，并在已评测范围内以 0.125 dB 网格收缩边界。没有任何覆盖充分的连续区间在 12 块上全部正增益；最稳的 `4.25–6.0 dB` 仍有 `-0.000425` 的最坏块。

## 结论

拒绝 V148，不合并 `main`、不制作提交包。半径 3 的平均信号为正，但不足以排除按区间选点产生的过拟合；冠军继续保持 V147。
