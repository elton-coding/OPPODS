# V225：低 SNR Receiver 专家

V225 保持 V224 Encoder/Transmitter 不变，将 Receiver 按单 UE SNR 分为 `[-20,0)` 与 `[0,20]` 两个专家。两个专家从 V224 克隆初始化，只训练低 SNR Receiver，损失仍为 V224 soft-score。

低区间固定验证从 60.140813 提升至 60.181768（+0.040954），但官方兼容 seed1176 全局分为 67.876608，低于 V224 的 67.890964（-0.014356）。说明局部增益不足以覆盖专家切换与发射映射不匹配，否决且不晋级主干。
