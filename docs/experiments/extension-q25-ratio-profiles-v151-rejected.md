# V151 中间输出 q25 一致性门控（盲测淘汰）

日期：2026-08-25  
分支：`codex/extension-q25-ratio-profiles-v151`  
对照：V149

## 方法

在完整固定集 2000×3 上生成 924-bit 回退与 1056-bit 扩展的逐 UE 配对得分，以

`q25(|extension LLR|) / (mean(|extension LLR|) + 1e-9)`

衡量扩展 bit 的整体一致性，并在 `[-20,-2.5) dB` 内按 2.5 dB 小区间搜索门槛。搜索约束三个固定 seed 的 final 均不低于回退策略。首箱阈值额外下移一个 float32 ULP，消除离线 float64 搜索与提交代码的边界选择差异。

## 结论

`q25/mean` 比 V150 的 q75 门控更稳健，并在第一条盲测上泛化，但每 seed 只改变个位数 UE，仍受高方差影响。seed2098/2099 后续转为验证集；seed2100 保持未触碰，并与新的 seed2101/2102 共同作为下一轮冻结盲测。下一步生成 2098/2099 的完整回退/扩展配对诊断，把搜索约束扩大到五个 seed 及其前后半块。
