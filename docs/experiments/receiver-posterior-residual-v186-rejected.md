## 方法

利用另一用户的软星座 posterior，计算软抵消后的条件残差：posterior 方差
加上未抵消软均值的剩余功率；新增
`INTERFERENCE_POSTERIOR_RESIDUAL_BLEND` 在 V156 的完整干扰功率残差与该
物理残差之间混合。默认 `0.0` 走原代码分支，保证正式对照逐项等价。

实现通过 Ruff 与 51 项测试。seed1176、500 样本官方兼容 exact 评测：

| 0.50 | 62.844883 | 0 | 0 | 0 |
| 1.00 | 62.844883 | 0 | 0 | 0 |

posterior 残差会改变部分 LLR 数值，但三个强度都没有改变任何硬判决 score
或输出长度，因而不存在可由 SNR 路由利用的反事实差异。
