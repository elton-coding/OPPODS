# SNR 分段 Receiver 与物理参数专家实验

日期：2026-08-24  
实验分支：`feature/snr-receiver-experts`  
对照：V117（三 seed 均值 `63.077458`）

## 1. 实验目标

将 `[-20,20] dB` 拆成独立区间，直接优化官方兼容链路得分，而不是只用重构损失判断专家优劣。所有晋级判断均采用固定 seed `1176/1177/1178`、每 seed 2000 个信道样本（4000 个 UE 分数）和 exact `0.7 * mean + 0.3 * P10`。

## 2. 已否决路线

### 2.1 神经 LLR 残差专家

实现了 12 个按 SNR 路由的 `LLRResidualExpert`，并支持 score、lower-CVaR、BCE、hinge、多训练 seed 参数平均。零初始化专家与 V117 exact 等价；训练后的候选在不同评测 seed 间正负不一致，未晋级。

### 2.2 低 SNR 短前缀

重新导出 V117 三 seed 的 1056 位完整前缀矩阵。代理搜索提出低于 `-12.5 dB` 使用 132 位，但直接 2000 样本 seed 1176 从短评正增益反转为 `-0.03898`。逐 0.5 dB 配对分析没有找到三 seed 共同为正的连续低 SNR 区间，因此否决。

### 2.3 全局物理参数修改

- 干扰抵消启用点 `-10 -> -7.5 dB`：2000 样本三 seed 约 `-0.00193/-0.00158/+0.00049`；
- 数据向量软温度 `3.0 -> 2.0`：约 `+0.00299/+0.00070/-0.00319`；
- 数据增益软温度 `0.5 -> 0.3`：约 `-0.00155/+0.00014/-0.00153`。

全局修改均至少有一个 seed 退化，但保存逐 UE score 后可以分解出稳定的局部 SNR 正贡献。

## 3. 晋级候选：互斥物理参数专家

最终仅保留三个 seed 在 2000 样本配对统计中都为正、且彼此互斥的区间：

| UE SNR 区间 | Receiver 策略 |
|---|---|
| `[-8.5,-8.0)` | 关闭软干扰抵消 |
| `[-2.5,0)` | 数据增益 posterior 温度 `0.5 -> 0.3` |
| `[0,2.5)` | 数据向量 posterior 温度 `3.0 -> 2.0` |
| `[2.5,5)` | 数据增益 posterior 温度 `0.5 -> 0.3` |
| `[5,7.5)` | 数据向量 posterior 温度 `3.0 -> 2.0` |

500 样本实现结果与离线逐 UE 合成结果完全一致：SNR、数据索引和 1000 个 UE score 全部逐项相等，最大绝对误差为 0。

## 4. 直接全量结果

| Seed | V117 | SNR 物理专家 | 增益 |
|---:|---:|---:|---:|
| 1176 | 62.952218 | 62.954162 | +0.001944 |
| 1177 | 63.155982 | 63.159628 | +0.003646 |
| 1178 | 63.124175 | 63.127517 | +0.003342 |
| 均值 | 63.077458 | **63.080436** | **+0.002977** |

三个 seed 的 P10 均与 V117 相同，因此增益来自 efficiency，未交换公平性。路由只增加标量区间判断，不增加神经权重或实质推理开销。

## 5. 工程改进

- `scripts/evaluate_submission.py --scores-out` 用于逐 UE 严格配对；
- `scripts/search_snr_prefix_policy.py` 支持多 seed 前缀策略联合搜索；
- `scripts/build_submission.py` 在构建非默认输出目录时自动复制 `modelDesign.py`，保证候选目录可直接打包；
- SNR 区间采用半开区间 `[low, high)`，并有边界单元测试。
