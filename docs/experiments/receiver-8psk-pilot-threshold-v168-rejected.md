# V168 8PSK 导频相位位起始阈值（拒绝）

日期：2026-08-25  
分支：`codex/receiver-8psk-pilot-threshold-v168`  
对照：V156

V156 从 `7.5 dB` 起把导频相位载荷由 2 位提高到 3 位。本轮在 seed1176 前 500 样本、同随机流下扫描 `7.0/7.25/7.75/8.0 dB`：

| 阈值 | 相对 V156 final |
|---:|---:|
| 7.0 | -0.000121 |
| 7.25 | -0.000243 |
| 7.75 | -0.002643 |
| 8.0 | -0.001367 |

四个方向均未超过当前 `7.5 dB`，且提高阈值的回退更明显。该候选每个受影响 UE 仅改变 1 个输出位，没有值得进入 6-seed discovery 的正信号。

结论：V168 初筛拒绝，不修改模型、不进入盲测、不构建包、不合并 `main`；冠军继续为 V156。
