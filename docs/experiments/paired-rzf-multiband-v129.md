# V129 双 UE 多区间 RZF 专家实验

日期：2026-08-24  
分支：`codex/paired-rzf-multiband-v129`  
对照：V128

## 方法

V128 证明了共享预编码器必须按两个 UE 的 SNR 联合路由。V129 保留 V128 的任意 UE 中低 SNR 专家，并新增一个“两个 UE 都进入高 SNR”的专家：

| 联合 SNR 条件 | 导频 RZF 正则 |
|---|---:|
| 任一 UE 位于 `[-10,-2.75) dB` | `0.40` |
| 两个 UE 都位于 `[-0.75,20) dB` | `0.90` |
| 其余组合 | `0.45` |

第二个条件使用 `all-user` 谓词，因为预编码器共享于两个 UE；只在弱用户也达到较高 SNR 时提高正则，能减小反馈误差带来的不稳定波束，而不会把高 SNR 用户的参数强加给低 SNR 伙伴。

## 扫描过程

全局使用 `0.50` 时三 seed 均低于 V128，但逐样本反事实显示“两个 UE 都高于 `-0.75 dB`”的子集三 seed 全正。固定前 1000 样本上的局部值扫描为：

- `0.475` 相对 `0.50` 三 seed 全负；
- `0.525/0.55/0.575/0.625/0.70/0.80/0.90` 总体持续上升；
- `1.0` 与 `0.90` 均值接近，但 seed1178 安全余量明显变小；
- `1.2` 均值开始回落；
- `0.95` 对 seed1176/1177 小升，但 seed1178 相对 `0.90` 回退约 `0.003555`。

因此按“所有固定 seed 不退化且保留最差 seed 余量”冻结为 `0.90`。
