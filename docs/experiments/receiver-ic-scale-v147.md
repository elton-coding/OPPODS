## 方法

全局扫描 `INTERFERENCE_CANCELLATION_SCALE=0.1/0.15/0.25/0.3`，保存逐 UE exact score，再按 UE SNR 精确重组局部反事实。`0.25` 是唯一在三个 500 样本开发 seed 上均显著为正的候选。为降低边界过拟合，将 1000 样本拆成前后两半，仅保留六个子集都为正且 P10 不变的区间：

- `[-7.75,-5.0) dB -> 0.25`；
- `[-0.25,2.75) dB -> 0.25`；
- `[8.0,18.0) dB -> 0.25`；
- 其他区间保持 V143 的 `0.2`。

三个区间的六子集最差收益分别为 `+0.001154/+0.000668/+0.000609`。真实路由在 1000×3 上与全局反事实重组逐 UE 完全一致，最大绝对误差均为 `0.0`。
