# V122 Receiver 小区间参数复扫

日期：2026-08-24  
分支：`feature/receiver-bin-v122`  
对照：V122

## 方法

依据 V122 的逐用户配对分析，优先检查 `[-7.5,-5)` 和 `[-5,-2.5)`。
所有粗筛使用 seed1176、300 样本，只对一个 SNR 小区间覆盖参数，其他
V122 参数不变。边缘候选再用 seed1177/1178 复核。

## 结果

1. `DATA_VECTOR_SOFT_TEMPERATURE`
   - `[-7.5,-5)` 扫描 `1/2/4/5`，全部低于默认 `3`；
   - `[-5,-2.5)` 的 `4` 在 seed1176 仅提升 `+0.000709`，但在
     seed1177/1178 分别退化 `-0.002633/-0.001215`。
2. `DATA_GAIN_SOFT_TEMPERATURE`
   - `[-5,-2.5)` 扫描 `0.2/0.3/0.4/0.7/1.0`；
   - `0.2` 在三个 seed 的变化约为
     `+0.000911/-0.000506/+0.005237`，方向不一致。
3. `DATA_GAIN_REFINEMENT_SCALE`
   - 新增默认为空的 `DATA_GAIN_REFINEMENT_SCALE_INTERVALS`，默认结果与
     V122 保持一致；
   - `[-5,-2.5)` 扫描基值 `0/0.1/0.15/0.25/0.3/0.4`；
   - `0.15` 在 seed1176 仅提升 `+0.000608`，seed1177 退化
     `-0.002329`，不满足晋级条件。

## 决策

本轮没有稳定候选，不合入 `main`。区间更新强度接口保留在特性分支，
便于未来与其他 Receiver 结构联合搜索；V122 冻结参数不变。
