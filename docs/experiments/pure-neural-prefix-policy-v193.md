## 1. 唯一改动

V192 的网络权重、专家路由和训练结果全部冻结，只改变官方 batch-size-one 推理时返回的 logits 长度：

| SNR | 输出长度 |
| --- | ---: |
| `[-20,-16.5)` | 1 |
| `[-16.5,-14.5)` | 132 |
| `[-14.5,20]` | 1152 |

训练模式和批量 validation 始终保留 1152 logits，因而该策略不会改变网络损失或反向传播。它不是物理接收算法，只利用评分规则中“未输出 bit 按 50% 计分”的接口语义。

阈值来自 seed1176 的完整前缀反事实搜索；该 seed 已降级为 discovery。搜索器已修正为把 1152 纳入完整输出候选，避免历史工具只比较到 1056。
