# V252候选：保留父模型分界的近等频八专家路由

2026-09-09代码分析。状态：仅完成路由分布推导，尚未实现候选或运行训练；不能计入提分实验结果。V250/V251继续占用两个GPU训练槽，禁止启动第三项训练。

## 已核实的实现

`research/pure_neural_v230/modelDesign.py`的`Transmitter._whole_min_forward`取两个用户SNR最小值，在[-20,-15,-10,-5,0,5,10,15,20]内分为8段，控制位通知Receiver使用对应专家。共享Encoder不参与路由。

`scripts/train_pure_neural_snr_experts.py`的calibrate默认两个SNR独立均匀采样[-20,20]，当前focus_prob=0；`scripts/evaluate_submission.py`亦独立均匀生成两个SNR。因此低SNR专家收到更多样本是由路由统计分布直接决定的，不是加载器丢数据或随机故障。

令M=min(SNR1,SNR2)，则区间[a,b)的概率为`((20-a)/40)^2-((20-b)/40)^2`。由代码采样分布推导，不使用任何test结果拟合边界。

| 原路由区间/dB | 样本概率 | batch100期望路由样本数 |
|---|---:|---:|
| [-20,-15) | 23.4375% | 23.4375 |
| [-15,-10) | 20.3125% | 20.3125 |
| [-10,-5) | 17.1875% | 17.1875 |
| [-5,0) | 14.0625% | 14.0625 |
| [0,5) | 10.9375% | 10.9375 |
| [5,10) | 7.8125% | 7.8125 |
| [10,15) | 4.6875% | 4.6875 |
| [15,20] | 1.5625% | 1.5625 |

首尾样本量相差15倍。最高段在batch100中完全没有样本的概率为`(1-1/64)^100≈20.7042%`。这是样本路由为空的概率，**不能直接等同于Adam参数不更新的概率**，因为优化器动量与梯度是否为None还影响更新。

## 候选分段设计

保留原父V227的-10dB分界，使初始化输出可复现；分别把[-20,-10)和[-10,20]各拆4段。前者总概率7/16，后者9/16，于是前4专家各10.9375%，后4专家各14.0625%。

候选边界（实现须保留完整精度）：

`[-20, -17.749172176353753, -15.355339059327378, -12.787192621510002, -10, -5.98076211353316, -1.213203435596423, 5, 20]`

边界由M的反CDF `20-40*sqrt(1-q)`确定；q为`[0,7/64,14/64,21/64,28/64,37/64,46/64,55/64,1]`。父专家映射机械调整为`[0,0,0,0,1,1,1,1]`，保证所有低于-10dB的输入仍由父低专家初始化，其余仍由父高专家初始化。不重新选择父模型。

这一因素是“八专家的区间划分”，同时改变专门化区域及每专家样本量；不能将潜在增益进一步拆称纯样本均衡收益。缺点是高SNR段更宽，可能损失高SNR细粒度专门化。也不能把等频视为天然优于等宽。
