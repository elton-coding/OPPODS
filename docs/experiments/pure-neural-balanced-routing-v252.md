`scripts/probe_pure_neural_routing_v252.py`用split1176中8个训练信道覆盖全部8专家，真实V227权重初始化；共享Encoder冻结，所有Tx/Rx参数实际执行反向传播，1296个梯度张量均有限。参数量190354976不变。证据`benchmarks/v252_cpu_runtime_probe.json`，仅为初始化/运行检查，不是性能分数。

首次批处理logits使用atol1e-4的检查失败：18432个logit中5个超限，最大差0.0005235672。未忽略这次失败，新增相同输入逐样本检查后确认逐样本最大差精确0；批处理硬判决差异0，损失差0；按父来源聚合Tx/Rx输出头梯度最大差分别5.36e-9、2.79e-9，信道随机流状态相同。由此将“函数初始化一致”与“分组GEMM批大小变化的舍入误差”分开：逐样本仍严格逐位相同，批处理要求决策相同并有界误差（atol1e-3/rtol1e-5）。不能把CPU小样本检查扩称完整验证集一致。

后续GPU探针保留完整batch100和原2000验证信道，执行2步，**在正式训练前**核对step0四项验证与V242E差异≤1e-4；失败则不启动36k。正式训练仍从原V227重新开始，探针权重不参与正式初始化。

## 已核实的实现

`research/pure_neural_v230/modelDesign.py`的`Transmitter._whole_min_forward`取两个用户SNR最小值，在[-20,-15,-10,-5,0,5,10,15,20]内分为8段，控制位通知Receiver使用对应专家。共享Encoder不参与路由。

`scripts/train_pure_neural_snr_experts.py`的calibrate默认两个SNR独立均匀采样[-20,20]，当前focus_prob=0；`scripts/evaluate_submission.py`亦独立均匀生成两个SNR。因此低SNR专家收到更多样本是由路由统计分布直接决定的，不是加载器丢数据或随机故障。

令M=min(SNR1,SNR2)，则区间[a,b)的概率为`((20-a)/40)^2-((20-b)/40)^2`。由代码采样分布推导，不使用任何test结果拟合边界。

| 原路由区间/dB | 样本概率 | batch100期望路由样本数 |
|---|---:|---:|
| [-20,-15) | 23.4375% | 23.4375 |
| [-15,-10) | 20.3125% | 20.3125 |
| [-10,-5) | 17.1875% | 17.1875 |
| [-5,0) | 14.0625% | 14.0625 |
| [0,5) | 10.9375% | 10.9375 |
| [5,10) | 7.8125% | 7.8125 |
| [10,15) | 4.6875% | 4.6875 |
| [15,20] | 1.5625% | 1.5625 |

首尾样本量相差15倍。最高段在batch100中完全没有样本的概率为`(1-1/64)^100≈20.7042%`。这是样本路由为空的概率，**不能直接等同于Adam参数不更新的概率**，因为优化器动量与梯度是否为None还影响更新。

## 候选分段设计

保留原父V227的-10dB分界，使初始化输出可复现；分别把[-20,-10)和[-10,20]各拆4段。前者总概率7/16，后者9/16，于是前4专家各10.9375%，后4专家各14.0625%。

候选边界（实现须保留完整精度）：

`[-20, -17.749172176353753, -15.355339059327378, -12.787192621510002, -10, -5.98076211353316, -1.213203435596423, 5, 20]`

边界由M的反CDF `20-40*sqrt(1-q)`确定；q为`[0,7/64,14/64,21/64,28/64,37/64,46/64,55/64,1]`。父专家映射机械调整为`[0,0,0,0,1,1,1,1]`，保证所有低于-10dB的输入仍由父低专家初始化，其余仍由父高专家初始化。不重新选择父模型。

这一因素是“八专家的区间划分”，同时改变专门化区域及每专家样本量；不能将潜在增益进一步拆称纯样本均衡收益。缺点是高SNR段更宽，可能损失高SNR细粒度专门化。也不能把等频视为天然优于等宽。

## 实现及后续运行前的门控

1. 独立特性分支`codex/pure-neural-balanced-routing-v252`，冻结复制V230设计，仅改边界；不得修改V250/V251绑定文件。
2. CPU验证边界、控制位编码/解码、8个路由、概率和，并以真实V227权重验证新/旧初始化端到端输出与梯度可运行。父映射变化必须维持初始函数，而非引入训练起点优势。
3. 主要对照V242E，同八专家RMS、batch100、Adam1e-5、seed15240、36k、验证2000，其余损失参数和训练信道分布不变。**不采用V251公平权重0.5，也不叠加V250的72k预算。**

5. 正式训练前另行冻结执行计划、输入/数据哈希、依赖及目标目录；必须完成36k，按官方验证分数选checkpoint。固定offset2000、3噪声、2000信道audit相对V242E配对，不利用offset4000确认窗口选择边界。
