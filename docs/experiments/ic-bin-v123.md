# V123 干扰抵消小区间扫描

日期：2026-08-24  
分支：`feature/ic-bin-v123`  
对照：V123，仅在 `[-8.5,-8.0)` 禁用软干扰抵消

在 seed1176、300 样本上，以 2.5 dB 粒度测试额外禁用
`[-10,-7.5)`、`[-7.5,-5)`、`[-5,-2.5)`、`[-2.5,0)`、`[0,2.5)`、
`[2.5,5)`、`[5,7.5)` 和 `[7.5,10)`。

V123 为 `62.420218`。所有候选均退化，范围为
`62.413129–62.418598`；最佳 `[-10,-7.5)` 仍低 `0.001620`。

结论：软干扰抵消在完整 2.5 dB 小区间总体有效，保留当前仅
`[-8.5,-8.0)` 的窄禁用窗口，不进入多 seed。
